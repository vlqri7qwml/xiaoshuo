# 第30章 一条缝

三天后，早上七点四十，二叔又往亲戚群里转了一篇文章。

还是明心灵修会的公众号，题目叫《致同修：清者自清》。

七点四十一分，表哥孟磊在底下发了一张截图。

那天是周日，孟实轮休。他坐在医院走廊的长椅上，把截图放大，一个字一个字看完了：

“近期，我局接到多名群众报案，反映‘明心灵修会’以‘开灵’‘消业’‘进阶’等名义收取高额费用。经查，澜城明心文化传播有限公司涉嫌非法集资、诈骗，我局已依法立案侦查，对其位于汇澜中心28楼的经营场所予以查封，公司实际控制人贺某远（男，46岁）等人已被依法带走调查。请相关参与人员携带缴费凭证，到市公安局经侦支队登记。”

落款是澜城市公安局。

又过了几十秒，群里跳出一行灰色的小字：

“孟大江”撤回了一条消息。

然后，群里就再没人说话了。三姑没再问，远房叔叔也没再提赔不是的事。

孟实又点开老乡群。“感恩遇见”那一大段话还挂在那儿，底下有人@她，问她贺老师咋回事，她没回。到中午再看，群成员里已经没有这个人了。

八点，护士站旁边那台挂在墙上的电视放早间新闻。

画面上是汇澜中心。镜头跟着几个穿制服的人进了二十八楼，玻璃门上交叉贴着两道白色封条。

那扇门孟实进过一回。三月底，檀香，低低的音乐，满屋子的人闭着眼睛发抖、流泪。现在镜头扫过去，落地窗还在，蒲团一摞一摞堆在墙角，地上散着几只印着莲花的纸盒子。

然后是一个背影。深灰色的中式立领，低着头，被两个人一左一右扶着胳膊，送进一辆车里。脸打了码。

可那件立领衫，孟实认得。

护士站的小护士端着杯子，看了一眼，嘀咕了一句：“又一个大师。”

邹婶站在电视底下，仰着脸，看了很久。

新闻已经换成了天气预报，说未来一周强对流天气频繁，请市民注意防范雷电。她还仰着脸站在那儿。

后来她回了病房，从编织袋里翻出一个塑料文件袋，里头是一沓收据。她把收据一张一张抹平，装好，跟孟实说：“实子，你帮婶看着点杰。”

她去了经侦支队。

中午十二点多，孟实的手机响了。

“实子……”

邹婶在那头，背景很乱，有人在吵，有人在喊“往后排，往后排”。她叫了一声“实子”，就哭了。

“婶……婶对不住你……”

就这一句。后面的话全叫哭声堵住了，她张了好几回嘴，一个整字也没说出来。

孟实握着手机，站在病房外头的窗户边上。

“婶，你排你的队。”他说，“阿杰这边有我。中午记着吃饭。”

那两个穿白衣裳的人，后来再也没来过。

第二天晚上，母亲打来电话。

她先说父亲的药吃着还行，这几天不怎么咳了；又说家里丢了一只鸡；又说前天下大雨，后屋漏了一块，你爸爬上去补的。

说了半天，才说到正事。

“那个会，真叫人给封了？”

“封了。”

母亲在那头叹了口气，又像是松了口气。

“你二叔昨儿来家里了，拎了两斤桃，问你爸身体。坐了半天，一句也没提群里的事。”

“嗯。”

“小卖部门口那几个，今儿见了我，也不像前几天那样了。”母亲顿了顿，声音里有一点压不住的东西，“村里人现在都说，还是实子稳当。”

孟实没接这话。

“妈，”他说，“别在外头说这些。邹婶家够难的了。”

母亲沉默了一会儿，“嗯”了一声：“你邹婶……也是可怜。”

挂电话之前，她又说：“你自个儿也吃好点。别光顾着别人。”

手串是阿杰自己说要摘的。

那是通报出来后的第二天下午。他半靠在床头，盯着左手腕上那串珠子看了很久，然后把手伸给孟实。

“你帮我摘了。”他说，“我手抖，解不开。”

绳结打得死，泡过汗，又干了，硬邦邦的。孟实抠了半天没抠开，找护士借了把剪子，一剪子下去，珠子哗啦一声，滚了半床。

阿杰的手腕上留着一圈白印子。别处的皮肤都晒过、蜕过，就那一圈是白的，像戴着一只看不见的镯子。

他拿右手的指头摸着那圈白印子，摸了很久。

“扔了吧。”

孟实把珠子一颗一颗捡起来，装进塑料袋，扔进了走廊尽头的垃圾桶。

停下来，比孟实想的难。

阿杰夜里睡不着。一闭眼，身子就自己往那个架势上找，盘腿，挺腰，气往下沉。他咬着牙不让自己坐起来，浑身冒冷汗，心慌得厉害，一夜按三回呼叫铃。

心理科的医生来过两回，调了药，说这个阶段难受是正常的，熬过去会一天比一天好。

第三天早上，阿杰喝完了一整碗粥。

他把碗递给孟实，忽然说：“维权群里，有人骂我。”

他把手机推过来。群是会里原来的学员群，改了名字，叫“明心维权”，三百多人，满屏都是数字：三万八，十二万，二十六万。也有人在骂，骂的是“邹家杰”三个字。骂他的人，是他当初拉进会里的。

“是我拉他们进去的。”阿杰说，“那时候，我是真信。”

孟实看着他。

他知道阿杰想听什么。想听一句“不怪你”，或者一句“你活该”。哪一句都行，哪一句都能让人心里落个地。

可这两句，他都说不出来。

“先把命养回来。”他说。

阿杰看了他半天，把手机扣在被子上，闭上眼睛。过了一会儿，他说：“嗯。”

又过了两天，维权群里传出消息：贺明远办了取保候审，人出来了。

群里一下又热闹起来，有人说要去他家门口堵人，有人说要凑钱请律师。可当天夜里就有人发：去了，家里没人，门上贴着物业的催缴单，手机关机。

第二天，第三天，还是没人。

再往后，谁也说不清他去了哪儿。

孟实在医院的卫生间洗了把脸，抬头看镜子。

在陪护的折叠椅上熬了十来天，夜里最多睡四五个钟头。镜子里那个人眼睛里有血丝，胡子也没刮，可眼底下是干净的，没有青。脸色也不是从前那种青黄，是正常人熬了夜的那种灰。

他把手伸到水龙头底下。凉水冲过手背，手是热的。

他已经很久没手脚冰凉过了。久到他都想不起，是从哪一天开始的。

那天又是他轮休，傍晚闷得像扣了一口锅。

孟实从医院出来，赶到柳巷菜市场口，老耿已经在收摊了。他接过鞋楦，按大小一个一个排进箱子。

卖豆腐的大婶在旁边收她的豆腐板，冲他努了努嘴，压低声音：“小孟，你看对面。”

菜市场对面的马路边，停着一辆黑色轿车。车窗贴着深色的膜，看不见里头。

“前天就在，昨天也在，今天又来了。”大婶说，“一停就是一下午，人也不下车。我看见过两回，车窗摇下来一条缝，就朝这边看。”

“看啥？”

大婶朝老耿的修鞋摊努了努嘴，没说话。

孟实又看了那辆车一眼。他想，大概又是一个来求老耿的。开豪车的女人，看了网帖的年轻人，生意赔了的老板——这几个月来的人多了，都是先在远处看，看够了才过来。

老耿没往那边看。他把补鞋机盖上布，说：“小孟，今晚跟我去河边。”

雷是九点多来的。

澜水河滩上没有灯，只有对岸的楼亮着，一排一排，倒映在水里。风先到，把河边的芦苇压得一边倒，带着一股河泥和水腥味。

老耿领他站在上游那座老石桥的桥洞底下。

第一道闪电劈下来的时候，孟实下意识缩了一下脖子。

那道闪电是直的，从云里一直扎进河心。整条澜水一下子白了，白得刺眼，对岸的楼，桥墩，水面上的每一道浪纹，都在那一瞬间清清楚楚。然后才是雷，炸在头顶，桥洞里嗡嗡地响。

第二道，第三道。

雨下来了，哗的一声，像有人从天上往下倒。

孟实看着那条一会儿白一会儿黑的河，忽然想起那个梦。一大片黑沉沉的水，他在水边守了不知多少年。

老耿站在他旁边，军绿外套的肩膀湿了一块。他看着河，看了很久。

“你身上的东西，清得差不多了。”

孟实转过头。

“门开了一条缝。”老耿说，“往后的路，我只能指，不能背。”

孟实张了张嘴。他想问什么门，开到哪儿去。可老耿没看他，还看着河。

又一道闪电落进水里。河面白了一下，又暗下去。

“天上下来的东西，最后都落到水里、地里，攒在一个地方。”

雷声滚过去，老耿的声音不高，混在雨里。

“几千年才开一回。”

孟实问：“开什么？”

老耿没答。

雷慢慢往东边去了。闪电离得越来越远，只在天边一亮一亮。雨还在下，不紧不慢，砸在河滩的石头上。

老耿朝桥洞外头抬了抬下巴：“去，站会儿。”

孟实走出桥洞，在河滩上找了一块平地。两脚与肩同宽，膝盖微屈，手松松地垂着。

雨一下就把他浇透了。

头发贴在脑门上，工装湿成了一张皮，雨顺着脖子往衣服里灌。他闭上眼，什么也不想，站着就是站着。

站了不知道多久，他觉出一点不一样。

雨是凉的。

这种凉他太熟了。三年来手脚冰凉，夜班车间里空调口往下吹的凉，冬天出租屋墙上返潮的凉——那些凉是往里钻的，钻进骨头缝里，攒着，散不出去。

这一回不是。

这一回的凉，是从外头落下来的。落到身上，就顺着身子流走了，什么也不留下。像小时候大夏天，母亲从井里压上来一桶水，兜头给他浇下去。

干净。

他想了半天，只找得到这个词。干净的，凉的，说不出的清。

他睁开眼。雨还在下，河还在流，对岸的灯还亮着。什么都没变。

可他站在雨里，觉得自己像是叫人从里到外洗了一遍。

回去的路上，雨小了。

老耿走在前头，背有点驼，脚步不紧不慢。走到河堤的台阶上，他忽然停下来，回头看了孟实一眼。

“留意下雨天——哪里的雨落下去，不积水。”

说完，他转身接着往上走。

孟实站在台阶上，愣了半天。澜城这一个月天天下雨，槐荫里的巷子里，积水能没过脚面。哪里的雨落下去，会不积水？

他们从柳巷菜市场口经过的时候，已经快十一点了。

菜市场早关了门，卷帘门上淌着水。老耿白天摆摊的那块地方空着，地上积着一小洼雨水，映着路灯。

对面马路边，那辆黑色轿车还停在那儿。

没开灯，雨刮器停在玻璃上。驾驶座那边的车窗摇下来一条缝，缝里有一点火星，亮了一下，又暗了。

孟实的脚步慢了一下。

老耿没停，也没往那边看，走过去了。

孟实跟上去。走出十几步，他又回了一次头。

那条缝还开着，对着菜市场口，对着那块空了的、积着雨水的地。

车里的人，已经连着三天，在看这个修鞋摊了。
