# 第27章 路口

雨是一下子砸下来的。

孟实冲下楼的时候，巷子里的地面已经白花花一片，水顺着墙根往下水口里灌。他连伞都没顾上拿，一路往巷口跑。

赵小满的大黑伞就在前头四五十米，在雨里一颠一颠的。

“小满！”

雨声太大，赵小满没回头。

跑到巷口小卖部门前，那股劲又上来了。

这一回比哪一回都重。胸口那床湿棉被像是又压上来一床，两床，他吸一口气，只吸进去小半口。头一下子晕得厉害，眼前的路灯、雨帘、红绿灯全在晃。胃里猛地一翻，他弯下腰，干呕了两声，什么也没吐出来。

冷汗和雨水混在一块儿，顺着脖子往下淌。

前两回，他都是往外走，走出来就好了。

这一回，他咬着牙，往里走。

烧烤摊的红蓝棚子底下亮着两盏大灯泡，雨砸在棚布上，噼里啪啦响成一片，棚沿往下挂着一道水帘子。这种天没几个客人，里头只坐了一桌，两个小年轻在喝啤酒。光头老板蹲在炭炉边上扇火，烟压在棚子底下散不出去。

赵小满已经坐下了。

最靠马路的那张折叠桌，一条桌腿不稳，拿黄胶带缠了好几圈。赵小满把大黑伞往桌边一靠，正冲老板喊：“老板，先来二十个肉串，十个板筋，两瓶冰的！”

孟实走过去，一把按住了他的肩膀。

“走。”

赵小满一扭头：“哟，你不是不来吗？坐坐坐，我都点好了——”

他看清了孟实的脸，话头一顿：“你脸咋这色儿？”

“走。”

“走啥走，串都点了。”赵小满把他的手往下扒拉，“你胸口闷你回家躺着，别耽误我……”

“我让你走！”

这一嗓子吼出来，孟实自己都愣了。

棚子底下一下子静了。光头老板的扇子停在半空，那两个小年轻端着啤酒转过头来，连站台底下躲雨的人都往这边看。

赵小满张着嘴，看着他。

认识这么久，被周广发当众罚款的时候，孟实没吼过；被冤枉偷货、被逼着签赔偿书的时候，孟实没吼过；被全班组的人喊“孟大仙”的时候，孟实也只是笑笑。

这是头一回。

赵小满的脸腾地红了：“孟实你吼谁呢？”

孟实没答。他两只手攥住赵小满的手腕，往外拽。

赵小满一百七八十斤，坐得稳稳当当的。孟实也不知道自己哪来的劲儿，一拽，塑料凳“哐当”翻倒在地上，赵小满踉踉跄跄被拖进了雨里。

“哎哎哎，兄弟，有话好好说！”光头老板站起来，“串还要不要了？”

“孟实你有病吧！撒手！你撒手！”

孟实不撒手。

他拽着赵小满，顶着雨过了马路，一步一步往巷子里走。赵小满一路骂，骂他神经病，骂他跟补鞋老头学魔怔了，骂他害自己在老板跟前丢人。大黑伞落在了烧烤摊的桌边，两个人都没打伞，从头到脚淋了个透。

走进巷子三十来米，到小卖部门前，那股劲一下子没了。

孟实松开手，一屁股靠在墙上，腿软得站不住。他撑着膝盖，大口大口地喘，喘着喘着又干呕起来。

赵小满骂到一半，停了。

“……你咋了？”

后街那家牛肉面馆不大，六张桌子，墙上挂着个旧电视，锅里的热气把玻璃门糊得白蒙蒙的。

孟实要了两碗大碗牛肉面，扫码付了三十六。

赵小满一屁股坐下，冷着脸：“加两份牛肉，再加个蛋。你掏钱。”

“嗯。”

孟实又付了十八。

面上来了，赵小满低头吃，吃两口就要骂一句。“我跟老板打了一礼拜招呼。”“我伞还落那儿了。”“以后我还咋有脸去那儿吃。”

孟实不吭声，由着他骂。

他的手还在抖，筷子夹不住面条。他看着玻璃门外头的雨，雨越下越大，后街的路面上已经汪成了一片，路灯底下全是白花花的水柱子。

他心里慢慢地凉下来。

万一什么事都没有呢？

那他今天就是个神经病。冲朋友吼了，当着一棚子人丢了脸，就为了一个说不清道不明的胸口闷。明天赵小满往班组里一说，“孟大仙”这名号就算是坐实了。

他宁可是这样。

赵小满吃完了一碗，抹了抹嘴，气消了一点，瞥他一眼：“你真胸口闷？”

“嗯。”

“那你得上医院啊。”赵小满皱着眉，“明儿我陪你去，挂个号查查。你家老爷子那肺……你别不当回事。”

孟实看了他一眼，点了点头。

雨太大，两个人一把伞也没有，只好在面馆里干坐着等雨小。墙上的电视放着本地新闻，又在说暴雨预警。

八点十几分。

隔着一条街，隔着那么大的雨，那一声还是传过来了。

闷的，沉的，像什么东西从高处整个砸在了地上。面馆的玻璃门嗡地颤了一下。

面馆里的人都抬起了头。

静了几秒，远处响起一阵汽车的报警器声，紧跟着是人的喊声，乱糟糟的，听不清喊的什么。

又过了几分钟，警笛响了。一声叠着一声，从远处往这边来。

玻璃门被人一把推开，一个送外卖的小伙子冲进来躲雨，头盔上的水哗哗往下淌，喘着粗气：“路口！槐荫路口！渣土车冲到烧烤摊上去了！”

赵小满手里的筷子掉在了桌上。

路口围满了人。

雨还在下，一把一把的伞挤在一起，伞面上的水连成了片。警戒线拉起来了，红蓝的警灯在雨里一圈一圈地转，把每个人的脸都照得一会儿红、一会儿蓝。救护车的灯也在闪，交警穿着荧光雨衣在雨里来回跑，吹着哨子把人往后赶。

人群里说什么的都有。

“刹车不灵了，从坡上直接冲下来的……”

“站台那儿有人，好几个……”

“幸亏下雨，要搁平时，这个点那棚子底下得坐满了……”

赵小满挤到了前面，孟实跟在他身后。

隔着警戒线，隔着雨，警灯一下一下地扫过去。

红蓝棚子已经没了。棚布塌在地上，泡在水里。几张塑料凳被冲到了马路牙子底下，在积水里打着转。公交站台的顶棚塌下来半边，站牌歪在一旁。

那辆渣土车的一只前轮底下，压着一张折叠桌。

桌面已经扁了。一条桌腿歪在车轮外面，上面缠着几圈黄胶带，被警灯照得一会儿红，一会儿蓝。

赵小满不动了。

孟实看见他的肩膀在抖。先是肩膀，然后是胳膊，然后整个人都抖起来，抖得站不稳。他伸手往旁边抓，抓住了孟实的手，死死攥着，攥得指节发白。

他张了几回嘴，一个字也没说出来。

雨水顺着他的圆脸往下淌，分不清是雨还是别的什么。

孟实站在那里，任他攥着。

他站在槐荫路口，站在那根贴满小广告的电线杆底下。

胸口不闷了。

不晕，不想吐，也不出冷汗。周三、周四、今天傍晚，一走到这儿就压得他喘不上气的那股劲，没了。干干净净，一点都没剩下。

满世界都是雨声、警笛声、人声，只有他胸口那块地方，空落落的，什么也没有。

他说不清为什么，这比闷着还让他害怕。

过了很久，赵小满才开口。声音是哑的，打着颤。

“你……你怎么知道的？”

孟实张了张嘴。

他发现自己也在抖。从攥着赵小满的那只手开始，一直抖到膝盖。

他不知道。

他真的不知道。

那天夜里，槐荫里的租户群一直在响。

一死四伤。伤的是烧烤摊的老板、棚子底下喝酒的两个小年轻，还有一个在站台躲雨的外卖员。

死的那个，是在站台等车的。

群里有人说，男的，四十来岁，穿一身灰工装，去城西一家冷库上夜班，天天这个点在那儿等车。有人说，他闺女今年高考，就这两天。又有人说不对，是儿子，在老家念书。

孟实盯着手机屏幕，盯着“灰工装”那三个字。

他想起周三晚上，站台最边上那个伸着脖子等车的男人。红网兜，不锈钢保温杯。

他不知道是不是同一个人。

赵小满没回自己屋。他抱着枕头过来，在孟实床边的地上铺了张凉席，躺下去，又坐起来。他从裤兜里摸出那包薯片，在手里捏了半天，没拆，又塞了回去。

快天亮的时候，他在黑暗里说了一句：“早饭……一个礼拜早饭，我请你。一个月。”

孟实没吭声。

周六一早，本地新闻推送了交警通报，就几行字：昨晚二十时十五分许，一辆重型自卸货车行驶至槐荫路口时，因制动失效，冲上人行道，造成一人死亡、四人受伤。事故原因正在进一步调查中。

孟实照常去上班。从后街绕的路。

一整天，复核台上的箱子一件件过，扫码枪“嘀”“嘀”地响。下午他扫错了一件。三个月来头一回。

五点下班，他去了柳巷。

老耿坐在小马扎上补一只布鞋，锥子扎进去，线拽出来，一针，一针。

孟实蹲在边上，把事情从头说了一遍。从周三晚上，说到昨天夜里的租户群。说到那张缠着黄胶带的桌子，说到站在路口胸口一下子空了。

他说得很慢，有几处说不下去，停一停，再接着说。

老耿一直没抬头。

等他说完了，锥子也停了。

菜市场口人来人往，卖菜的在吆喝，电动车按着喇叭挤过去。老耿就那么坐着，手里捏着那只布鞋，很久很久没有说话。

久到孟实以为他不会说了。

“祸事到之前，那地方早就有东西等着了。”老耿说，“你感觉到的，是它们。”

孟实脊梁上一凉。

等着。

周三，周四，周五。那股劲在那个路口压了他三天。昨晚八点十五分以后，没了。

等着的东西，等到了。

他手心里全是汗，攥了攥，又松开。

老耿把布鞋放下，看着他。

“能感觉到，是好事，也是担子。”老耿说，“别声张。”

孟实低着头，半天没动。

“耿师傅。”他开口，嗓子发紧，“那个等车的人……”

他没说下去。

周三晚上，他从那个人身后走过去，离他不到三步。那时候他胸口已经闷了。他要是转过身，跟人家说一句，大哥，这站别等了，往前走一站——

人家会怎么看他？当他是个神经病。

可万一呢？

他有三天。三天里，他想的是自己的病，想的是自己熬了三个月白不白费，后来想的是赵小满。他没想过站台底下那些等车的人。他也没想过那个光头老板，那两个喝酒的小年轻。

他想过又能怎么样？去跟烧烤摊老板说，你这摊子别摆了？给交警打电话，说那个路口要出事，因为我胸口闷？

谁信？

可那个人，天天那个点，在那儿等车。

老耿没答。

他端起铁皮箱上的搪瓷缸，递过来。

孟实接过去。缸子是烫的，粗茶的味儿冲上来，有点苦。他两只手捧着，捧了很久，手才慢慢不抖了。

他想起分拣线上的箱子。干了九年搬运，他知道有些箱子看着不大，面单上写的也轻，一上手，才知道沉。沉到手腕子一下子往下坠。

这东西，他是拿起来了。放不放得下，由不得他了。

收摊的时候，天又阴了。

孟实把鞋楦按大小排进箱子，一个，一个。排到一半，他抬头往菜市场里头看了一眼。

卖豆腐的大婶那个摊子后面，蹲着一个人。

圆脸，印着卡通熊的大背心，手里攥着一包薯片，正假装挑豆腐。挑了半天，一块也没拿。

卖豆腐的大婶拿刀背敲了敲案板：“小伙子，你到底买不买？”

那个人一缩脖子，躲到了豆腐摊的遮阳布后头。

孟实低下头，接着排鞋楦。

老耿也没抬头，往三轮车上码着铁皮箱，淡淡说了一句：“跟你来的？”

“……嗯。”

孟实想起老耿刚才那句“别声张”，又往豆腐摊那边瞥了一眼。

赵小满那张嘴，从来就没把过门。
