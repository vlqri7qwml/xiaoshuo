# 第26章 胸闷 · 润色修改说明（中度）

润色前 3438 字 → 润色后 3438 字。开头“周三这天，孟实加班到七点。”与结尾“‘当’的一声，跟敲在他心口上一样。”原样保留；老耿“哪个路口？”“这几天，别走那个路口。”“搁那边，三号。”与赵小满“神神叨叨”“三千六”“一个礼拜早饭”等台词一字未动。灰工装男人、红网兜、保温杯、七点五十/七点五十八、暴雨橙色预警等细节全部保留。感应只写胸闷、头晕、想吐、冷汗，全程强调“什么也没有”，孟实以为旧病复发。

## 节奏
- “孟实从他身后走过去，往斑马线那边走。/就在这时候，胸口一下子闷住了。” → “孟实从他身后过去，往斑马线那边走。/刚走到电线杆跟前，胸口一下子闷住了。” → 原因：删“就在这时候”套话，同时把发作位置钉在电线杆，和后文“到小卖部门前就消失”的范围对上。
- “下午复核台来了一批大件，他抢着去搬……心跳稳稳的，气也匀。同组的大姐看他一眼……”一段 → 拆成搬货、大姐问话、孟实按胸口三段 → 原因：长段拆短，大姐的话单独成段。
- “他没答，站在二楼的铁栏杆边上，手搭着栏杆，一口一口地喘匀了气。” → “他没答。站在二楼的铁栏杆边上，他把手按在胸口，心跳稳稳的，气也匀。” → 原因：原句“喘匀了气”与“心跳平稳”相冲，改后直接引出下一句“哪有病，只在一个路口犯？”，疑点更清楚。

## 对话
- “‘小满，换个地方。’他说，‘后街那家牛肉面，我请。’” → “‘小满，换个地方。后街那家牛肉面，我请。’” → 原因：去标签，孟实的话短而直。
- “‘反正那儿不行。’他说，‘换个地方。’” → “‘反正那儿不行。’他翻来覆去就这一句，‘换个地方。’” → 原因：把标签换成性格描写，写出孟实嘴笨、说不过赵小满。
- “‘我查了……’他说，‘我爹就是……’” → “……他嗓子发干，‘我爹就是……’” → 原因：去“说”字，用生理反应带出对父亲病情的恐惧。
- “‘这几天，别走那个路口。’老耿说。” → 删“老耿说”，前一段改为“往槐荫里那个方向看了一眼” → 原因：台词不动，让老耿的话孤零零落地，更像一句压下来的话。

## 文笔
- “不是疼，是闷。” → “不疼，就是闷。” → 原因：清理“不是A，是B”句式。
- “眼前的东西像隔着一层晃荡的水。” → “跟他从前下了十二个钟头夜班、从传送带边上猛地站起来时一模一样。” → 原因：去掉带视觉意味的比喻，换成孟实自己熟悉的身体记忆；同时让他自然联想到旧病复发。
- “他走得像在齐腰深的水里蹚。” → “他每一步都得先想好往哪儿落脚。” → 原因：本段已有“泡透水的棉被”，再用水比喻会重复，改成具体动作。
- “工装贴在背上，冰凉冰凉的” → “冰凉”；“隔着两条街，那边什么也看不见，只有……楼顶” → “那边只有……楼顶” → 原因：删叠词和重复的“看不见”。
- “一样一样地试，一样一样地往下掉” → “一样一样地试，钱一样一样地往外掏” → 原因：“往下掉”指代不明，改为具体的钱。

## 爽点
- 本章为加压章，无释放。压抑层层叠加：身体（发作两次、进退试三回）→ 心理（“再熬熬”头一回觉得不像话，不敢给老耿打电话）→ 外界（老耿第一次皱眉却不解释）→ 人情（赵小满不信、执意去路口）。结尾雷雨原样保留，压力全部留给第27章释放。
