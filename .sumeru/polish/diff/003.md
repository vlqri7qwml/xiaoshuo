# 第3章 一个整觉 润色修改说明（中度）

润色前 3453 字 → 润色后 3530 字。开头“下午四点四十，孟实就到了柳巷菜市场口。”与结尾“三千六，就响了那么一声。”原样保留；老耿台词（“来了。坐会儿，还剩这一双。”“收吧。”“从小往大装。小的在里，大的在外。”“几点睡？”“睡得着？”“早饭吃不吃？”“就这些。”“走吧。”“随你。”）一字未动；“走吧”时孟实毫无感觉的写法未动。

## 节奏
- “今天调休。早上八点下了夜班……腿肚子发软。”一整段 → 拆成两段，“夜里搬猫砂时眼前那一黑，还压在身上”单独成段 → 原因：压抑段落拆短，前一章的透支感延续下来。
- “孟实把手机揣回兜里，在药房门口站了一会儿。”删去；面馆一段压成一句“他吃了半碗就吃不下了……” → 原因：压缩转场，给释放段腾字数。
- “可灵修营那回不一样……跟打了鸡血似的。” → “……亢奋得停不下来。”；“他提醒自己：别忘了八千八。” → “别忘了八千八。” → 原因：余波里的自我辩驳去掉套话，直接写成心里话。

## 对话
- “孟实愣了愣，才说：‘上夜班……’” → “孟实愣了愣：‘上夜班……’”；“孟实憋了一会儿，问：” → “孟实憋了一会儿：” → 原因：去对话标签。
- “‘不是。’孟实说，‘补过鞋。’” → “‘不是。’孟实顿了顿，‘补过鞋。’” → 原因：一个停顿写出他嘴笨、不知道怎么介绍自己和老耿的关系。
- 老耿问完后“像是刚才问的是‘吃了没’，问完就算” → “刚才那几句，就跟问了声‘吃了没’一样，问完就算” → 原因：去“像是”，更贴孟实的口吻。

## 文笔
- “像有人把这十五个钟头从中间整个儿剪掉了，前头一下接着后头。” → “眼睛一闭，再一睁，十五个钟头就过去了，中间齐齐整整剪掉了一截。” → 原因：去比喻词，改成动作，读着更像人醒来后的直觉。
- 新增“卤菜店的大锅咕嘟咕嘟冒着八角味，老板娘拿眼角瞟了他两回。” → 原因：观望段补嗅觉和旁人眼光，孟实的局促不用说出来。
- “这几年吃饭跟上班一样，是件得完成的事” → “这几年吃饭跟上班打卡一样” → 原因：比方落到他自己的生活上，去掉解释性的半句。

## 爽点（压抑 → 蓄力 → 释放 → 余波）
- 压抑：面馆里“八点，三号线该开了”保留，空荡感原样。蓄力：入睡前补“肉块在锅里翻着油花，那人慢条斯理地说，火别大，等。” → 原因：入睡前把节奏放慢，睡意一点点漫上来。
- 释放（新增）：醒来补一段“楼下有人吆喝‘收旧手机旧电脑’……这些动静他听了两年，从来是隔着耳塞、隔着帘子往脑子里钻。这会儿就在窗外，清清楚楚，一点也不扎耳朵。” → 原因：用两年来扎耳朵的同一种噪声对照，写出睡足以后的松弛，不靠形容词。
- 释放（新增）：“嘴角有一道干了的口水印子。”“三年来，头一个整觉。”单独成段；“他站起来，伸了个懒腰，浑身骨节‘咔吧咔吧’响了一串。” → 原因：点明本章题眼，再用身体的反应把释放落到实处，克制，不写成神迹。
- 余波：“笑完了，眼眶有点热，他抬手搓了一把脸” → “笑完了，眼眶发热，他抬手搓了一把脸，手心里湿了一片。” → 原因：情绪越到顶越平静地写，让手替他哭；镜中“脸还是黄的，乌青一点没少”保留，变化合理、有保留。
