# 第18章 一句真话 · 润色修改说明（中度）

润色前 3220 字 → 润色后 3481 字（老耿的台词逐字保留，增量全部用在河滩的静和深上）

## 节奏
- 新增下河滩的过渡：“下到最后一级台阶，身后的城一下子远了。堤挡住了路上的车声，烧烤摊的吆喝，夜市的喇叭，都隔在了那道水泥坡后头。” → 从夜市油烟到河滩，中间先给一道“声音关掉”的门槛。
- 新增回程：“上到堤顶，车声、喇叭声一下子又涌回耳朵里。” → 与下去时首尾呼应，一下一上，把河滩的静框住。
- 原来一段写完的河滩，拆成“鹅卵石、芦苇、气味”和“看不清的河面、对岸灯影”两段 → 段落更短，读来有停顿。

## 对话
- “‘你的。’老耿说。／就两个字。说完，他转身……” → “‘你的。’／就两个字。说完，老耿转身……” → 删标签，两个字单独成段。
- “孟实说我来蹬吧，老耿不让。” → “孟实想说我来蹬吧，老耿不让。” → 话还没出口就被拦下，更像孟实嘴笨。
- “孟实……说这回我来蹬。” → “……推出来：‘这回我来蹬。’” → 回程改成直接引语，和来时“想说”没说出口形成对照。
- 老耿全部关键台词（“对了。就是这样。”“这世上修行的路，有三千条。九成九，是给人借东西的。”“真路不在书上，在人心里。”“灵气没开。市面上卖的，都不是。”“等你站得住了再说。”“你身上的东西，我帮你清了七成。”“剩下三成，得你自己熬。”“回去好好吃饭。”“你小时候，是不是常做同一个梦？”）一字未动。

## 文笔
- “河风吹在脸上，凉丝丝的，挺舒服。他听见水拍着岸，很轻，一下，一下。” → 补“隔好一会儿才来一下。芦苇叶子擦着芦苇叶子，沙沙的。再远就什么都没有了。” → 用间隔变长的水声写静。
- 新增对照：“在澜城九年，他没听过这么静的地方。出租屋墙薄，听得见隔壁赵小满打呼，分拣线上的轰隆声半夜也不停，连睡着了，耳朵里都嗡嗡的。” → 拿他九年的噪声来衬，静就落到了实处。
- “天黑透了，河面看不清” → 补“分不出哪儿是滩、哪儿是水”；补“空气里是河泥和水草的味道” → 用视觉和嗅觉写出河的深，不写阴森。
- “这不是谁跟他说的，不是在哪个屋子里，跟着音乐，闭着眼，被人一句一句引着感觉出来的。是他自己一天一天过出来的。” → “没有谁跟他说过，也没有哪间屋子、哪段音乐、哪个让人闭上眼的声音一句一句引着他去感觉。他自己一天一天过出来的：……” → 清理“不是A，是B”。
- “跟河边随便哪个出来乘凉的老头” → “出来遛弯的老头” → 四月底夜里河风凉，“乘凉”不合时令。

## 爽点（倾泻章：压抑→蓄力→释放→余波）
- 蓄力：“老耿没答，看着河。”后新增运沙船的余浪：“推起来的浪这会儿才到岸边，哗，哗，一下比一下大……最后没了。河面又平了，对岸的灯重新拼起来。” → 老耿开口前，河先静下来，“三千条路”那句在静里说出来，分量更足。
- 释放：“对了。就是这样。”和“七成／三成”两处原样保留，前面孟实腿抖、心沉、想起贺老师那句“根骨太浅”也全部保留 → 压得住，释放才有落差。
- 余波：孟实眼眶发热时，新增“河还是那样流着，一下，一下，拍着岸。没人看他。” → 他的情绪由河来接，不写哭，不说教。
- 结尾“堤底下，澜水在黑暗里流着，一点声音都没有。”原样保留 → 与前面一下一下的水声相对，梦的钩子更沉。
