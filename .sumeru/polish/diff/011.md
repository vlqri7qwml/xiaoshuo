# 第11章 一万二 润色说明（中度，旋转门一段重写加深）

润色前 3261 字 → 润色后 3567 字。开头（夜里十一点四十的电话）和结尾（七个勾、“嘀。/再熬熬。”）原样保留；4126.37、300+214、4386.00、4月15日、12624/每期52、下午五点截止、借三千/两千、一天一百八、转九千剩126.37 全部未动；老耿“借来的，早晚要还——还的时候，不是钱。”按第9章原话加引号复现。

## 节奏
- “工资还得十来天才发。” → “工资还得等到十五号。” → 当天是4月8日夜里，离发薪日只有一周，“十来天”不准；改后与全局设定“每月15号发薪”一致。
- “下午他到底没睡着。阿杰那条语音没回，也没删，他爬起来……” → “下午他到底没睡着，爬起来……” → “没回也没删”是上一章结尾原话，紧接着再说一遍是重复交代。
- “一个多月了……老耿没问他要过一分钱。没让他买过一样东西……连一句‘你得信我’都没说过。” → “……老耿没问他要过一分钱，没让他拜过谁，没让他发过什么心。” → “没让他买过一样东西”“连一句你得信我都没说过”与第10章原句重复，删去，留下灵修会特有的“拜”“发心”做对照。
- “周广发推开更衣室的门，进去了。” → “更衣室的门推开，又合上了。” → 一个画面收住“谁家里没点事？”，门合上比“进去了”更冷。

## 对话
- “‘妈。’孟实说，‘钱的事我来。’” → “‘妈。’孟实攥着手机，‘钱的事我来。’” → 用动作代替“说”，嘴笨的人一句话就揽下来。
- “‘我借你一万。’阿杰说，‘今天就转。’” → “‘我借你一万。今天就转。’” → 去标签，阿杰说话又快又亮，不需要停顿。
- “‘我都听见了。’他说。” / “‘小满。’孟实说，‘借我三千。’” → 去掉“他说”“孟实说” → 前一句已有人物动作，说话人清楚。
- “卸车口白班缺人……一天一百八。”孟实说，“我问过了。” → 合成一句“……一天一百八。我问过了。” → 孟实话不多，一口气说完，事先打听好的实诚劲儿出来了。
- 赵小满“我是说，他帮不上这个” → “我是说，这个他帮不上。” → 语序更口语。

## 文笔
- “大楼的玻璃幕墙一直戳到云里，二十八楼是哪一层，他数不清。” → “……一直戳进云里。二十八楼是哪一层，他数不清。” → 断句，让“数不清”单独落地。
- “所有的空都填满了” → “该填的空都填满了” → 口语化。
- “孟实低下头，看了一眼那块补丁。” → “孟实低下头，看那块补丁。针脚是他自己缝的，歪歪扭扭，有一针扎偏了，线头支棱在外面。” → 补丁从“老耿给的”落到“自己缝的”，具体到一根线头，克制不煽情。
- “走出去很远，他才发现自己的手在抖。不是冷的。” → “……手在抖。他把两只手插进裤兜，攥成拳头，还是抖。/不是冷的。” → 加一个想压住却压不住的动作，“不是冷的”单独成段。

## 爽点（心性高光：旋转门前的挣扎，按“拉—近—停—醒—算—走”重写）
- 原：孟实始终“站在台阶下头，没动”，挣扎主要靠回忆铺陈 → 改：“他攥着手机，往上走了一级台阶。”“又上了一级。”“再一级。”“他的脚停在最后一级台阶上。”……“他往下退了一级台阶。” → 把心里的拉扯落到脚下的台阶上，一步一步看得见，诱惑越近越具体。
- 新增旋转玻璃里的倒影：“藏蓝工装，膝盖上一块深色补丁，眼下两块青，手里攥着一部碎了屏的手机。玻璃转过去，人没了，换成大堂里亮堂堂的大理石地。又一扇转过来，又是他。” → 让他在门口看清自己，与“送件的走侧门”呼应，不写一句评判。
- 第8章回忆加深：原“满屋子的人都热了，就他一个人冷” → 补“后来是一屋子的笑声，一浪推着一浪。他走的时候，前台那个白衣姑娘笑着说，随时欢迎回来。/现在他回来了。膝盖上打着补丁。/这回呢？这回他要是也热起来了呢？/他站在门口，心里真盼了一下。/就一下。” → 写出最真实的诱惑：他也想热一回。承认动摇，转身才有分量。
- 算账收到硬皮本子上：新增“今天按了那个蓝按钮，最后一行底下，就得再添一行：一万二千六百二十四。/八千八那回，也是一个万一。三千六那回，也是。一千八，一千二，回回都是万一。” → 回收第10章“空着大半页”的伏笔，用他自己的账本回答“连个万一都不肯给”，不靠说理，不靠老耿开口。
- 转身仍只有一个动作：“孟实把手机锁上，揣回兜里。/他转过身，下了台阶。” → 前面压足，这里不加任何心理解释，干脆利落。
