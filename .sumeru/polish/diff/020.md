# 第20章 饭局 · 润色修改说明（中度）

## 节奏
- 婶子催婚长段一口气说完 → 拆成两段，中间插“她往孟实碗里又拨了一筷子菜。” → 长台词分轮，动作透出“热心”和“扎心”同时在。
- “菜是从主桌那头开始上的。等红烧肘子端到这一桌，主桌那边已经吃上第三道菜了。” → “菜从主桌那头开始上。等红烧肘子端到这一桌，主桌已经吃上第三道了。” → 压缩交代，座次落差更利落。
- “他走过女眷那一桌的时候，看见母亲低着头在夹菜。” → “走过女眷那一桌的时候，他看见母亲低着头在夹菜。” → 语序调顺，藕片细节原样保留。

## 对话
- “说话的是三表婶……热情得很。” → “三表婶隔着两个孩子伸过筷子来。” → 用动作带出说话人，去“很”。
- 阿杰“他说，‘我们会里有体验课……’”／“眼神诚恳得很” → 删标签，改“眼神是诚恳的” → 阿杰的好意是真的，避免写成反派，为第21章翻底留余地。
- “‘谢谢你，杰子。’孟实说，‘不用了。我现在挺好。’” → “他把杯子往上抬了抬。／‘谢谢你，杰子。不用了。我现在挺好。’” → 关键台词一字不改，去标签，以动作起句，嘴笨实诚的人只说三句短话。
- 二叔“语重心长”删去；“阿杰睁开说”改“睁开：” → 让台词自己带出口气。

## 文笔
- “没人听懂，但大家都鼓掌。” → “支书愣了愣，带头鼓了掌。” → 与第19章“没人听得懂高维是什么，但都点头”去重，换成具体人的具体反应。
- “不是从前那种睡不着，是心里有事。” → “身上不乏，是心里搁着事。” → 去“不是A，是B”。

- “他吃得很慢” → “他吃得慢” → 删空洞副词，扣肉凝油的细节保留。
