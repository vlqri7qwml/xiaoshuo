# 第14章 不争 · 润色修改说明（中度）

## 节奏
- “‘不争，不是不说。’老耿说，‘是不带火气地说。’” → 拆成两段，中间插一个动作“他用拇指抹了一下鞋跟上的灰。” → 老耿台词原字不动，用停顿给这句话留出分量。
- “他把那几句话翻来覆去地嚼” 前删去重复的“孟实”；“他在槐荫里巷口的小卖部买了一本横格信纸” → “在槐荫里巷口的小卖部，他买了一本横格信纸” → 转场更利落。
- “周广发看了两秒，没说话，背着手走了。” → “周广发看了两秒，背着手走了。” → 删冗余。

## 对话
- “‘我在这园区干了十一年。’她说” → “她把饭盒换了只手” → 用动作替代“说”，写出马红霞的犹豫。
- “孟实说：‘姐，我不让你难做。……’” → “‘姐，我不让你难做。’孟实搓了搓手” → 孟实嘴笨，用手上的小动作代替标签。
- 马红霞：“别让人再挑出一个错来。” → 末尾加“听见没有？” → 刀子嘴的口气更足。
- 赵小满：“我吃我的饭，碍着谁了。” → 加“这椅子写他周广发名字了？” → 嘴碎、仗义，又不抖机灵。

## 文笔
- “‘走吧。’老耿眼睛没看他，看着他身后，淡淡说了一句。” → 删“淡淡说了一句” → 去掉多余的修饰，红线内的普通动作照旧。
- “每个字都是火” → “字字带火”；“字写得又大又歪，笔尖把纸都戳破了。” → “字又大又歪，笔尖把纸戳破了两个洞。” → 更具体。
- “此起彼伏，像一窝被惊动的鸟。” → “嗡的，叮的，还有一个放着歌，响成一片。” → 用声音细节代替比喻。
- “心里那团火，还在，只是没那么烫了。” → “心里那团火还在，没那么烫了。” → 句子收紧。
