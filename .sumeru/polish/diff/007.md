# 第7章 老乡 润色说明（中度）

润色前 3154 字 → 润色后 3164 字。开头、结尾原样保留；人名、数字（800/816/三万/二十四期/1250/四千九/650/两千/四百）及事件顺序未动。

## 节奏
- “他下了夜班回出租屋，只眯了三个钟头，眼睛还有点涩。” → “下了夜班，他回出租屋只眯了三个钟头，眼睛还发涩。” → 交代压短，尽快把镜头推进包间。
- “两句话在他脑子里来回撞，撞了一宿。” → “……撞到后半夜。” → 与后文“脑子里那杆秤，晃了一宿”避免重复，两处“一宿”只留收束那一处。
- “是一张业绩排名表，他的名字排第二……” → “业绩排名表，他的名字排第二……” → 删去判断句的“是”，画面更直接。

## 对话
- “‘半年前，我是真不行了。’阿杰说。” → “‘半年前，我是真不行了。’ / 阿杰把公筷搁下，叹了口气。” → 去掉“说”字标签，用动作带出说话人。
- “‘没用。’他说，‘开头好像有点用……’” → “‘没用。’他拿筷子头在碗沿上蹭了蹭，‘……’” → 孟实嘴笨，用小动作替他把难堪说出来。
- “孟实沉默了一会儿：‘……要多少钱？’” → “孟实憋了半天，问出一句：‘……要多少钱？’” → 更贴孟实笨嘴实诚的人设。
- 赵小满：补“你小子背着我下馆子？”“端茶倒水都行”“天底下就没有白给的” → 强化嘴碎心善、苦中作乐的口吻，同时侧面点出老耿“不要钱”的反常。

## 文笔
- “可贺老师不一样，贺老师是有真东西的” → “可贺老师有真东西” → 去掉“不是A，是B”式对举的变体，阿杰的话更干脆。
- “三万块，是他不吃不喝干半年还不够。” → “三万块，他不吃不喝干半年还不够。” → 删冗余判断词，算账段落更像心里默算。
- “低声说了句：‘感恩。’” → “低低地念了一声：‘感恩。’” → “念”字带出仪式感，暗示这是灵修会的习惯动作。

## 爽点（本章为蓄水章，以“压”为主）
- 保留“阿杰半年，月入两万。/他一个月，轻了。”与两句台词对撞的结构，只收紧前后交代，让动摇的落点更集中。
- “那是八百块一桌的菜，到他嘴里，跟食堂的也差不多。” → “八百块一桌的菜，到他嘴里，跟食堂的也差不多。” → 收短，让落差更利落。
