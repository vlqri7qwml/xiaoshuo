## 节奏
- “那头半天没出声，最后挂了。” / “后来，就再没联系过。” → “那头半天没出声，最后挂了。之后就再没联系过。” → 两段并一段，回忆收得更快，尽早回到急诊。
- “窗外是空荡荡的街。澜城这个月就没干过，雷一阵接一阵。” → “澜城这个月就没干过，雷一阵接一阵。” → 删掉空转的景物句，前文已有“巷子里一个人都没有”。
- “孟实认得这身衣裳。三月底那次体验课，二十八楼里走来走去的，就是这身衣裳。递水，放音乐，领着满屋子的人闭眼睛。” → “……二十八楼里走来走去，递水、放音乐、领着满屋子人闭眼睛的，就是这身衣裳。” → 三句合成一句，交代不再拖尾。

## 对话
- “‘他在医院。’孟实说，‘心脏的病，刚从急诊转上来。’” → “‘他在医院。心脏的病，刚从急诊转上来。’” → 去掉对话标签，前一句“孟实接了”已经交代了说话人。
- “‘二十四万三。’阿杰说，‘信用卡四张……’” → 直接连成一段台词，后面接“阿杰说得很平，像在给客户报一张保单” → 标签挪到台词后面，跟神态描写合成一句。
- “‘会里的人说了，这是排业。’她小声说，像在说给自己听” → “她声音小小的，像说给自己听” → 用声音状态代替“说”。
- “阿杰盯着他，眼眶一下红了。” → “他眼眶一下红了。” → 删去重复的“盯着”，质问的节奏更紧。

## 文笔
- “可不知道为什么，这四个字比‘猝死’两个字更叫他后背发紧，像大热天有人往他领口里塞了一块冰。” → “可这四个字比‘猝死’更叫他后背发紧，跟大热天有人往领口里塞了块冰似的。” → 删掉“不知道为什么”这类虚词，比喻改成口语说法。
- “第一医院的急诊大厅灯火通明。” → “……灯火通明，消毒水味里混着一股酸馊气。”并补上“保洁阿姨拎着拖把骂骂咧咧地过来” → 补足气味和人声，急诊的乱是实打实的。
- “他把小票对折，揣进裤兜。” → “窗口里吐出一张小票，还带着打印机的热乎气。他对折了一下，揣进裤兜。” → 一千块变成手里一张还热的小票，钱的分量落到实物上。
