## 节奏
- 按“压抑→蓄力→释放→余波”重排轻重：四点路过纸箱堆（压）→ 五点二十拦错单（蓄）→ 七点半念数、八点当众表扬（放）→ 群消息、老耿“轻了”、阿杰私信（余波）。
- “他看了一眼，走过去，站到格口边上等车。” → “……站到格口边上等车。没坐。” → 加两个字，把上周睡岗的阴影压进动作里，压抑段压得住。
- “前天下午又出了一身虚汗……结果汗出完了，人反倒松快了。” → “……汗出完了，人反倒松快了。” → 删去多余的“结果”。
- “昨天，他睡了七个半小时”后各段只做删字，不加铺垫，开场尽快回到线上。

## 对话
- “‘这件面单不对。’孟实把箱子转过来给她看，‘……面单上却是城西一个私人地址。我估计是打包的时候贴串了。’” → “孟实把箱子转过来，指头点着面单角：‘这件……不对。……地址却是城西的，私人的。我估摸是打包的时候贴串了。’” → 孟实嘴笨，说话带停顿、用短词，“估摸”更像他。
- “‘一码归一码。’他说，‘零错件是本分……’” → “‘一码归一码。零错件是本分……’” → 原话不动，去掉标签，上一句“嘴角往下一拉”已交代说话人。
- “‘柳巷。’孟实说，‘他就是补鞋的。’” → “‘柳巷。’孟实挠了挠后脑勺，‘他就是补鞋的。’” → 用动作代替“说”，写出被人求问时的不自在。
- “‘耿师傅，’他说，‘明天我还来。’” → “‘耿师傅，’他抬起头，‘明天我还来。’” → 台词原样；“抬起头”接住前面“低下头假装看链条”，情绪收住再开口。

## 文笔
- “以前一到三点，眼皮就像坠了秤砣” → “眼皮就往下坠” → 本章比喻偏多，删去一处。
- “在传送带上一溜排过来，像一个模子里磕出来的。” → “……一个模子里磕出来似的。” → 少一个“像”字句，口语化。
- “地址也不是城南那家门店，是城西一个小区” → “收件人那一栏换了个名字，地址也换了，城西一个小区” → 清理“不是A，是B”句式。
- “那一眼不长，也不重，可看得人心里不太舒服。” → “……看得人心里硌了一下。” → 空泛的“不太舒服”换成具体的身体感受。
- “赵小满从兜里摸出一颗奶糖，剥了糖纸塞进嘴里，含混不清地说” → “赵小满剥了颗奶糖塞进嘴里，腮帮子鼓起一块” → 去掉“说”标签，用画面带出嘴碎的样子。

## 爽点（释放写足，“被看见”）
- 念数一段补出夜班老规矩和以往的样子：“以前念到他，后头总跟着个数，三件，五件，马姐念完还要拿眼睛剜他一下。他就低着头，盯着自己的鞋尖。/今天念到他，她停了一下……像是怕自己看错了。” → 先压后放，“错件，零”有了落差。
- 新增“前后几个人扭过头来看他。那几道目光落在他脸上，没带笑。”“枪把被手心焐得发潮”“赵小满……拿胳膊肘捣了他一下，没说话” → 第一次写他被人看见，不靠喝彩，只写目光和手心。
