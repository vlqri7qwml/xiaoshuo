# 第12章 过坎 润色说明（中度，倾泻章）

润色前 3204 字 → 润色后 3426 字。开头（第三天下午一点半爬出货车厢）和结尾（二楼办公室两人盯着屏幕）原样保留；九米六、一百八、四五个钟头、十九/十七、两碗粥三个包子一个茶叶蛋再添一个、两点半自然醒、八天前、保价好几千等均未动；老耿全章唯一一句“过了一道坎”和周广发“走路都打飘了，还逞能”一字未改。身体变化全部用写实细节呈现，没有任何感应描写。

## 节奏
- “那几天的日子，是按钟点切开的”之后，原文直接进入收摊 → 补一段身体代价：“肩膀先磨破了……揭下来火烧火燎地疼。接着是手，十个指头肿得发胖，早上醒来攥不拢拳头。拿冷水一冲，指头就白了，木了，甩半天才缓过来。” → 压抑段压得更实，为后面“冷水冲过手还是热的”埋好对照。
- “是十九。是他自己看岔了。” → “十九。是他自己看岔了。” → 删一个“是”，节奏更紧。
- “回城的公交上，孟实没睡着。” → 前面加“公交车进站，孟实一步跨上去，没去扶门边的把手。”再接“回城路上，他没睡着。” → 一个动作把“腿不飘了”再落一次，与第三天睡过站形成前后对比。
- “他妈说，‘钱的事，慢慢来……’” → 合并为一段台词，去掉“他妈说” → 母亲的话一口气说完，少一处打断。

## 对话
- 赵小满打赌原为叙述 → “赵小满跟他赌了一包辣条：‘大包的啊。我赌你撑不过第四天。’”；第七天早上补“……辣条我认了，大包的。” → 嘴碎的人连输都要输得有来有回，前后一呼一应，余波里自带笑意。
- 马红霞放鸡蛋原只有动作 → 加“吃了。晕在线上，我还得找人抬你。” → 刀子嘴豆腐心，温鸡蛋配一句狠话。
- “‘没有？’赵小满又摸了一把，‘不烫啊。’” → “……‘脑门不烫啊。’” → 说清摸的是脑门，与“手这么热”区分开，误会更好笑也更准确。

## 文笔
- “不是熬夜熬出来的那种心慌的虚饿，是干了一宿活、身子要东西吃的那种饿。” → “熬夜熬出来的饿他知道，心慌，发虚，扒两口就顶住了。这回的饿，是干了一宿活，身子跟他要东西吃……” → 拆掉“不是A，是B”，两种饿各给具体表现。
- “脸色也不是原来那种青黄，往暗里说是黄……” → “脸上那层青黄也褪了些，往暗里说是黄……” → 去掉否定式，用“褪”写渐变，变化合理、不夸大。
- “看着那一屉一屉的包子” → “看着那一屉一屉冒热气的包子” → 补一处视觉与温度，引出“咽了一口唾沫”。
- “手心是红的，指头是热的。刚拿冷水冲过，这会儿那股热……” → “手心是红的，指头是热的，指甲盖底下透着粉。刚拿冷水冲过，没发白，也没发木，那股热是从里头往外透出来的。” → 指甲颜色是能看见的血色；“没发白也没发木”回扣前文冷水冲手的样子。
- 走四百米：“鞋底一步一步落在水泥地上” → “今天飘着毛毛雨，他没打伞……鞋底一步一步落在湿水泥地上” → 接上“第七天的夜班是在一场小雨里熬完的”，场景连贯。

## 爽点（压抑→蓄力→释放→余波）
- 压抑：保留刘班长“没见过谁撑过三天的”、睡过站、周广发冷笑、十九看成十七；新增肩膀磨破、手指肿胀发白，老耿“正摁在磨破的地方，他咧了咧嘴，别的什么也觉不出来” → 拍肩照旧，孟实只觉得伤口疼，守住“第26章前无感应”的红线。
- 蓄力：父亲稳住、押金凑齐（“交上了”）原样保留，情绪的石头先落地，身体的变化才有空间冒出来。
- 释放：按“饭量→手热→脚热→镜子→四百米→马姐→上车不扶把手→自然醒”逐层推进，每一层都是普通人能看见、摸到的变化；醒来补“中间一回没醒，脑袋是轻的，眼睛也不涩”。
- 释放的顶点（工具箱）：原“他弯下腰，两只手抠住箱底，一使劲，箱子离了地。” → 先补“锤子、钳子、锥子、成盒的鞋钉，一箱子铁家伙，死沉”，再写“铁皮的棱角硌着小臂……放进三轮车的车斗里，‘咚’的一声” → 写出箱子的分量和落下的声音，“没叫老耿搭手”才有份量；第9章他还抬不起这只箱子，前后对照不靠解释。
- 余波：老耿的笑、大婶“难得见他乐”、对旋转门的回想、夜宵的丢货传闻全部保留，不让孟实高调，只让他“把手揣回兜里，往公交站走”。
