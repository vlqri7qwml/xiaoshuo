润色前 3254 字 → 润色后 3193 字。开头、结尾原样保留；36.8℃、78元、两百出头、二百与三百罚款、群消息原文、一分半一轮、五点三十八、备忘录记录均未动；老耿两句台词“屋子脏了多年，扫的时候灰最大。”“不想来，明天就别来。”原样保留。

## 节奏
- “比以前还难受。/以前是睡不着，熬，没精神，可从没这样过。” → “以前是睡不着，熬，没精神，可从没遭过这份罪。” → 删掉单独成段的“比以前还难受”，与上文“比不睡还累”不再重复。
- 路口回顾里“灵修营，头一个礼拜浑身发热，一宿不睡都精神，后来一路往下掉。” → “灵修营，头一个礼拜浑身发热，后来一路往下掉。” → 前文已详写过灵修营的“头一个礼拜好得出奇”，这里只点一笔，不重复。
- “这一回，那个整觉，老耿从来没提过，好像跟他一点关系都没有。” → “这一回，那个整觉，老耿提都没提。” → 第 4 章已用过“好像跟他一点关系都没有”，这里收短，避免单元内重复。
- “他说不清这到底算什么。他只知道，它跟以前那些不一样。” → “他说不清这到底算什么，只知道跟以前那些都不一样。” → 两句并一句，路口的转念更利落。

## 对话
- 孟实质问：“我这些天，冷得打摆子，出虚汗，一天拉五六趟，夜里一个梦接一个梦……说再有一回就让我滚。” → “我这些天……冷得打摆子，出虚汗，一天拉五六趟。夜里一个梦接一个梦……罚了三百。说再有一回，就让我滚。” → 拆短、加停顿，孟实嘴笨，气头上是一截一截往外蹦，不像背好的稿子。
- “‘周主管，’赵小满从格口那边挪过来，声音不大，‘他这两天拉肚子……’” → “赵小满从格口那边挪过来，声音不大：‘周主管，他这两天拉肚子……’” → 先写动作再说话，嘴碎心善的她在主管面前也只敢小声。
- “‘不想来，’老耿说，‘明天就别来。’” → “‘不想来，明天就别来。’” → 台词一字不改，去掉标签，一口气说完更冷，前一段“看了孟实一眼”已交代说话人。
- “我以前是睡不着，可从来没这么遭罪过。” → “我以前是睡不着，可没这么遭罪过。” → 口语收短。

## 文笔
- “他骂了自己一句，觉得自己疯了。” → “他觉得自己疯了。” → “骂了自己一句”第 2、4 章都用过，清理重复措辞。
- “可浑身骨头缝里往外渗酸……说是热，其实就是一层虚汗冒出来，冒完了更冷。” → “可骨头缝里往外渗酸……说是热，其实就是冒一层虚汗，冒完了更冷。” → 删冗字，动词前置。
- “风从路口灌过来。” → “风从路口灌过来，带着菜市场的鱼腥味。” → 补一处具体气味，路口这场戏有了实感。
- “来的路上，他把要说的话在心里翻来覆去过了不知道多少遍” → “来的路上，要说的话他在心里过了一遍又一遍” → 去掉堆在一起的修饰。
