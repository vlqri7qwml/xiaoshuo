# 第27章 路口 · 润色修改说明（中度）

润色前 3358 字 → 润色后 3504 字。开头“雨是一下子砸下来的。”与结尾“赵小满那张嘴，从来就没把过门。”原样保留；老耿台词“祸事到之前，那地方早就有东西等着了。你感觉到的，是它们。”“能感觉到，是好事，也是担子。别声张。”“跟你来的？”一字未动。事故时间（二十时十五分许）、一死四伤名单、黄胶带桌腿、36 元/18 元面钱、一个月早饭、周六扫错件全部保留。事故只写人群、雨、警灯、塌棚和人的反应，无血腥特写。

## 节奏
- 新增“他看了一眼手机。八点零六。” → 原因：蓄力段给一个具体钟点，读者知道离“八点十几分”只差几分钟，等待的紧张感压住。
- 新增面馆老板娘“剥一颗，往碗里丢一颗”及巨响后“老板娘手里那颗蒜掉在了地上” → 原因：用一个日常动作铺平静，再用它被打断标出释放的一瞬，不加任何渲染。
- “孟实松开手，一屁股靠在墙上” → “孟实松开手，后背往墙上一靠” → 原因：动作更顺，避免与下文赵小满“一屁股坐下”重复。

## 对话
- 冲进棚子那段，孟实只说“走。”“走。”“我让你走！”三句，原样保留 → 原因：嘴笨的人急了只会这一个字，第三句吼出来就是全章压抑的顶点，不加修饰。
- 赵小满面馆里的碎骂（“我跟老板打了一礼拜招呼。”“我伞还落那儿了。”）与“明儿我陪你去，挂个号查查”保留 → 原因：嘴碎和心善在同一顿饭里，人设已立住，不动。
- 老耿两句关键台词保留“老耿说”标签，不改为动作 → 原因：全章只有这两处让老耿正面说话，标签留着反而压得住，显得平实不玄。

## 文笔
- 新增“每往前一步，胸口就沉一分。路口还是那个路口，红灯，站台，几个躲雨的人，什么也没有。” → 原因：逆着发作往里走，是本章最重的压抑；同时守住红线，孟实只有身体感觉，什么也看不见。
- “雨水顺着他的圆脸往下淌，分不清是雨还是别的什么。” → “……他也不擦。” → 原因：去掉套话，用不擦脸写出赵小满吓呆了。
- “只有他胸口那块地方，空落落的，什么也没有。” → 删“什么也没有” → 原因：与前文“干干净净，一点都没剩下”重复。
- “他没想过站台底下那些等车的人。他也没想过……” → 合为一句；“他想过又能怎么样？” → “想过又能怎么样？” → 原因：减少“他”字开头的重复，自问更急。

## 爽点（倾泻章：压抑→蓄力→释放→余波）
- 压抑：保留孟实九年第一次吼人的对比段，新增逆着胸闷往里走的一段，压抑压在身体上，也压在面子上。
- 蓄力：面馆里“万一什么事都没有呢？……他宁可是这样。”保留，加钟点“八点零六”，让等待有刻度。
- 释放：在“桌腿缠着黄胶带”之后新增“最靠马路的那张。/也就一个钟头前，赵小满就坐在那儿，冲老板喊先来二十个肉串。” → 原因：释放的那一下落在“那张桌子本该有人”，后怕写足，又不写血。
- 余波：新增“右手虎口还发酸，是拽赵小满时攥出来的。他把那只手举起来，在黑暗里看了一会儿” → 原因：用身体记忆写后怕和沉重；孟实不高调、不得意，接着是扫错件、老耿“担子”、等车人的追问，余波落在“由不得他了”。
