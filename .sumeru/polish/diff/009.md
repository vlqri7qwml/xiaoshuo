# 第9章 借来的 润色说明（中度）

润色前 3169 字 → 润色后 3358 字。开头、结尾原样保留；老耿三个问题、“那不是他们自己的”“人家给你点甜头，那是放贷”“借来的，早晚要还——还的时候，不是钱”“箱子”“你还得熬。最难的一段，在后头”“走吧”一字未改；朋友圈时间与文案、硬皮本数字未动。

## 节奏
- “跟了老耿快一个月，这是孟实头一回心平气和地，把自己心里压着的事从头说给他听。” → “……这是孟实头一回把心里压着的事，从头到尾说给他听。” → 删去与情绪不符的“心平气和”，句子更顺。
- 释放段重排为“回到那间屋子的画面 → 冷热对照 → 我没被放贷 → 罚单开错了人 → 一屋子签了借条的人 → 零首付”，层层推进，每段一个意思。
- “孟实回过神，重新弯腰” → “孟实重新弯腰” → 前文已有“回过神”，删重复。

## 对话
- “‘嗯。’老耿说。” → “‘嗯。’老耿没抬头。” → 老耿话少，用不抬头写出他在听又不表态。
- “‘就我一个人，啥也没有。’孟实说” → “……孟实手里的鞋楦转了半圈” → 去标签，用手上的小动作写他的局促。
- “‘耿师傅，’他说，‘那我……’” → “‘耿师傅，’他搓了搓手上的灰，‘那我……’” → 同上。

## 文笔
- “两个人不认识似的，说的却几乎是同一句话。” → “两个人互不相干，说的却几乎是同一句话。” → 更准确（两人其实认识）。
- “泡了一包挂面” → “煮了一把挂面” → 挂面需煮，修正生活细节。
- “要是放在一个礼拜以前” → “要是放在昨天” → 时间更贴：昨天他还在电梯里认命。

## 爽点（压抑→蓄力→释放→余波）
- 释放前新增画面回放：“昨天那间屋子，又在他眼前亮起来……戴金表的男人，手抖得表盘一闪一闪。围丝巾的女人，一礼拜不去就心慌。阿杰，哭了四十分钟，一天只睡四个钟头……” → 把第8章的“热”逐个重看一遍，让信息差落到具体的人身上。
- 新增“满屋子的人都热了，就他一个人冷。冷的那个，是没欠账的。” → 直接翻转第8章那句“满屋子的人都热了，就他一个人冷”，释放的一下打在原处。
- 原有一屋子笑他的人中补入“贺老师弯下腰拍他的肩膀：不怕你浊，就怕你不发心。” → 让最体面的那句羞辱也在翻转中被重新看清。
- 新增“还有前台墙上那块烫金的木牌……可分期，零首付。/零首付。/先拿走，往后慢慢还。/孟实在那四个字上停了一下，嘴角动了动，没笑出来。” → 用价目牌上的“零首付”扣上“放贷”，暗爽清晰但不浮夸，孟实不高调。
- 余波段朋友圈照片新增“满屋子举着的胳膊里，就这两只手没举。” → 第8章的难堪变成第9章的清醒证据，再转入对阿杰的担心。
