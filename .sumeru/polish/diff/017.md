# 第17章 两百块 · 润色修改说明（中度）

润色前 3535 字 → 润色后 3575 字（压缩前半的折腾段，把省下的字数放到被冤枉、回头垫钱那段）

## 节奏
- “分了一个钟头。分完了，长的短的排成七八小堆” → “分了一个钟头。长的短的排成七八小堆” → 删重复的“分完了”。
- 删“老耿还是那个老耿，话不多说一句，可干活的规矩变了。” → 直接从“从前鞋楦排好了，他看都不看；今天他每遍都看”起 → 下一句已经写出了变化，前一句是多余的总结。
- 灵修营回忆删“导师从身后走过，谁的腰塌了，就在谁背上拍一下”，开光大师删“坐在椅子上” → 八千八、三千六、磕头等事实保留，回忆不抢主线。
- “他请了假，回去的大巴票还没抢着，五一的票紧。” → “他请了假，大巴票还没抢着。” → 票紧的意思后面抢票时已有，这里压缩。

## 对话
- “‘我没拿。’他说。” → “‘我没拿。’” → 删标签，下一句“声音一出来，他自己都吓了一跳”就是说话人的动作。
- “‘不是我拿的。’他说。声音还有点抖，可每个字他都说清楚了，‘但您要是缺，我先垫上。’” → 拆成三段：“‘不是我拿的。’／声音还有点抖，可每个字他都说清楚了。／‘但您要是缺，我先垫上。’” → 关键台词一字未改，拆开后两句各自落地，前一句辩白，后一句担当。
- 新增“胖子张了张嘴，又闭上了。” → 旁人一句话也接不上，用沉默衬出这句话的分量。
- “‘哑巴老太太，你知道吧，捡瓶子那个。’大婶说，” → 删“大婶说” → 大婶一口气往下说，更像菜市场里的嘴。

## 文笔
- “孟实站在那儿，像是被人从背后兜头浇了一盆凉水。” → “孟实两只手还搭在工具箱的提手上，腰弯着，就那么僵在那儿。” → 原比喻“从背后兜头”自相矛盾，换成一个定住的身体动作。
- “那不是这两个月来她看他的眼神。那是菜市场里的人，看一个手脚不干净的人的眼神。” → “刷子在案板上嚓嚓地响，比刚才响。这两个月，她看他从来没这样过。菜市场里的人看手脚不干净的，就是这么看：瞥一眼，赶紧挪开，好像多看一会儿要沾上什么。” → 去“不是A，是B”，用刷案板的声响写出大婶的心虚和疏远。
- “他把铁盒放回工具箱，扣上了箱盖。” → “他把铁盒放回工具箱，箱盖一扣，咔哒一声。” → 补声音，让这一下落定在寂静里。
- “声音不大，可收摊的这一小片地方，一下子就静了。” 后补“修手机的小伙子那扇卷帘门拉到一半，停住了” → 用前文已交代的人和物写出全场静止。

## 爽点（加压章：压抑写足）
- 回头前新增“一辆电动车按着喇叭从他身边擦过去，骂了一句什么，他没听清。” → 他站在路口发愣的那几秒写实，压抑不说破。
- 新增“他捏着信封，在路边又站了一会儿。他知道这钱一放进去，在旁人眼里，跟认了差不多。大婶会这么想，胖子会这么想，明天整个菜市场口都会这么想。” → 写出垫钱的真实代价：钱垫出去，在旁人眼里就像认了。他明知道还是回去，这一段就有了分量。
- “他捏着信封往回走。” → “他把信封攥紧了，往回走。” → 一个“攥紧”，把下定决心落到手上。
- 大婶揭底与结尾“站了很久”原样保留 → 余波克制，不替孟实抒情。
