# 第10章 停滞 润色说明（中度）

润色前 3215 字 → 润色后 3171 字。开头（手机从床沿滑落、10:41）和结尾（“他没回。/也没删。”）原样保留；睡眠记录、三百八/四百五、2:10 宕机、清到上午十一点、¥12,000/¥30,000、硬皮本子四笔数字均未动；老耿的“轻了”“坎”“照旧”“你还得熬。最难的一段，在后头。”一字未改。本章为蓄水章，以“退”和“疑”为主，改动偏轻。

## 节奏
- “可从上礼拜起，一切都停住了。/不是一下子坏回去，是一点一点往回退。先是入睡慢……” → “可从上礼拜起，一切都停住了，接着一点一点往回退。/先是入睡慢……” → 去掉“不是A，是B”句式，退步的过程直接接在“停住”后面，少一层转折。
- “系统两个多钟头后才恢复。/积压的货，一直清到第二天上午十一点。/八点该下班的时候……” → 先“两个多钟头后，系统才恢复”，再“八点该下班了……”，最后“积压的货，一直清到上午十一点” → 原来时间先跳到十一点又倒回八点，现按时间顺序走，十一点放在马姐送水之后，紧接“十一点半，回城的公交”。
- “前些日子不是这样的。那几个零错件的夜班……” → “零错件的那几个夜班……” → 删去判断句，直接用对比画面说话。
- “无非是灵修营先甜后苦，老耿这儿先苦后甜，眼下又苦了。” → 去掉“无非是” → 让孟实的乱想更像脑子里冒出来的念头，少一层下结论的口气。

## 对话
- 马红霞送水原来没有台词 → 加一句“喝！嘴唇都起皮了，一个个还当自己是骆驼。” → 刀子嘴豆腐心：掏钱买水，嘴上照样不饶人；对孟实仍是“看一眼、皱眉、没再说什么”，克制不变。
- “说完，他把鸭脖袋子往孟实手里一塞，脑袋一歪……” → “……往孟实手里一塞：‘吃，别光愁。’脑袋一歪……” → 赵小满嘴上损“补鞋的能补人”，手上塞吃的，一句话把“嘴碎心善”补齐。
- “周广发打着电话从办公室出来，脸黑得像锅底，冲着电话那头吼：” → “周广发攥着电话从办公室出来，脸黑得像锅底：” → 删去“冲着电话那头吼”这个标签，台词本身已经是吼。
- “孟实张了张嘴，想问坎是什么，坎在哪儿……又咽了回去。” → “孟实张了张嘴。坎是什么，坎在哪儿，要熬多久，过不去怎么办——话到嘴边……” → 把“想问”去掉，四个问题直接压上来，更像嘴笨的人憋在喉咙里的话。

## 文笔
- “脑子醒着，像分拣线上那条皮带，一直转，停不下来。” → “脑子醒着，跟分拣线上那条皮带似的，转个不停。” → 比喻改口语，删去“一直转”与“停不下来”的同义重复。
- “像在看一张一个月比一个月少的工资条。” → “……一个月比一个月薄的工资条。” → “薄”是能摸到的东西，比“少”具体。
- “膝盖蹭掉一块皮，渗出几个血点子，火辣辣地疼。” → “……渗出几个血点子，风一吹，火辣辣的。” → 加一个触觉触发点，不加重伤情。
- “挤一挤，不是挤不出来。” → “挤一挤，也挤得出来。” → 去掉双重否定，口气更像他在心里算账。
- “鞋楦……按大小往箱子里码” → “按大小往纸箱里码” → 与全局设定“鞋楦装纸箱”统一，避免和铁皮工具箱混淆。
