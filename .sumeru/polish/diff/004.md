# 第4章 不要钱的才最贵 润色说明（中度）

润色前 3160 字 → 润色后 2987 字。开头、结尾原样保留；人名、数字（四点五十八/五点四十/十二块/三千六/五六千/一万多）、睡眠记录及事件顺序未动；老耿的台词（“后生，喝口。”“干啥？”“夜宵少吃。下了班别看手机，天亮就睡。”“不贪，不求，不怕吃亏。”“我就是补鞋的。”“鞋要补，搁下。不补，别挡道。”）一字未改。

## 节奏
- “不要钱的才最贵”推演整段（灵修营免费体验课、刷了八千八、吊坠“我不收你钱，就跟你说两句”、“先给你点不要钱的……再一刀一刀地割”，约 272 字）→ 压成“不要钱的才最贵。那些人哪个不是先给你点不要钱的，等你离不开了，再一刀一刀地割。/可老耿连这个‘先给’都没有……”（约 141 字）→ 免费体验课、吊坠的细节与第 2 章重复，这里只留“老耿连先给都没有”这个新角度；八千八、三千六在第 2、7、17 章和本章赵小满台词里都有，删去不丢设定。
- “这是他来收摊的第七天。……第七天，孟实到底没憋住。” → “……孟实到底没憋住。” → 删去重复的时间交代，前文已点明第七天。
- “自打睡了那个整觉，他就开始记。说不清为什么要记，大概是被坑怕了” → “……他就开始记。大概是被坑怕了” → 删去自问自答式的铺垫。
- “他骂了自己一句。老头统共就交代了三条……” → “老头统共就交代了三条，头一天他就破了一条。” → “骂了自己一句”第 2、5 章都有，这里删去，懊恼靠后半句自己带出来。

## 对话
- “‘耿师傅，’他说，‘我……就光收摊？’” → “‘耿师傅，我……就光收摊？不用干点别的？’” → 去掉“他说”标签，上一段已经是孟实视角，说话人很清楚。
- “‘就是……’孟实不知道怎么说。” → “‘就是……’/就是什么，他也说不上来。……/他搓了搓手：‘您总得让我做点啥吧。’” → 嘴笨用动作和心里卡壳来写，不靠“不知道怎么说”直接交代。
- “孟实想了想：‘反正……不要钱。’” → “孟实把纸杯捏瘪了，又捏圆：‘反正……不要钱。’” → 用小动作带出说话人，也写出他心里没底、嘴上硬撑。
- “‘不贪，不求，不怕吃亏。’老耿说。/说完，蹬上三轮车走了。” → “‘不贪，不求，不怕吃亏。’/老耿说完，蹬上三轮车走了。” → 台词原样，标签并进动作句，一句扎心之后立刻走人。

## 文笔
- “跟老家长辈送人出门时拍的那两下，没什么两样。” → “跟老家长辈送人出门时拍的那两下一样。” → 和结尾“跟这条街上任何一个摆摊的老头，没什么两样”避开同一说法。
- “茶是粗茶，又苦又涩，泡得发黑……” → “粗茶，泡得发黑，又苦又涩……” → 删去判断句，先颜色后味道，感官顺序更顺。
- “他张了张嘴……话到嘴边，自己先听出来了——这话说出去” → “……自己先听出来了：这话说出去” → 少一处破折号，语气更平。
- “没有‘某某大师’的名头，一张照片都没有。” → “……连张照片都没有。” → 口语化，加重“搜不到”的空。

## 爽点（本章为加压章，以“压”和“疑”为主）
- 黑轿车一场原样保留推信封的动作链（锥子不停、手背一推、低头接着扎线），只把“那人愣了一下，脸上的笑僵住，又堆起来”收成“那人脸上的笑僵了一下，又堆起来”，让对比集中在老耿“连眼皮都没抬一下”。
- 压缩推演后，“老耿连先给都没有”和结尾“要是有人把钱送到跟前，他都往外推呢？”前后呼应，悬念从“他图什么”自然推到“他到底是什么人”。
