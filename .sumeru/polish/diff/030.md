## 节奏
- 两个人对视、群里的通报、邹婶的电话都保持原顺序，只压缩连接句：“说了半天，才说到正事。” → “绕了半天，才绕到正事上。” → 母亲电话东拉西扯的劲用一个“绕”字带出来。
- “‘门开了一条缝。’老耿说，‘往后的路，我只能指，不能背。’” → 拆成三段：雷声滚远、只剩雨声 → “门开了一条缝。” → 一句旁白 → “往后的路，我只能指，不能背。” → 台词一字未改，前面留出空白、后面留出回响，这一句才压得住。
- “这一回不是。这一回的凉，是从外头落下来的。” → “这一回的凉，从外头落下来，落到身上，就顺着身子流走了” → 删掉过渡短句，释放那一下连贯着写完。

## 对话

- “‘先把命养回来。’他说。” → “‘先把命养回来。’” → 单独成段，不加标签，孟实这句话更硬。
- “过了一会儿，他说：‘嗯。’” → “过了一会儿，才‘嗯’了一声。” → 用动作代替“说”。
- “他把补鞋机盖上布，说：‘小孟，今晚跟我去河边。’” → “他把补鞋机盖上布：‘小孟，今晚跟我去河边。’” → 动作直接带出老耿的话。
