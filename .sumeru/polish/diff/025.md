# 第25章 雨季 · 润色修改说明（中度）

润色前 3292 字 → 润色后 3283 字。开头“回澜城的第五天，雷已经打了四场。”与结尾“周五晚上，路口那家。我请！庆祝你脱离夜班苦海。”原样保留；老耿台词“咸了点。好吃。”“开了口子了。”“等你不急的时候。”及孟实“转你一千。剩下的别交了，去看病。”一字未动。余额 2316/1316/1327、四十分十二秒、217 路、六点五十等数字全部保留。

## 节奏
- “收摊的时候雨又大了。……前后二十分钟。这些活他干了三个月，用不着过脑子。” → “收摊时雨又大了。……前后二十分钟，手比脑子快。” → 原因：转场压缩，一个短句代替两句交代。
- “老耿从来不说没用的话。可老耿说过的话，也从来不解释。孟实早学会了不追着问，问了也白问。他只把这句话……放在一处，搁在心里头。” → “老耿从不说没用的话，说了也从不解释。孟实早学会了不追着问。他把这句话……搁在一处，收进心里。” → 原因：删“问了也白问”这类重复交代，三句并两句。
- 开头扫码枪一段、渣土车辙一段、阿杰朋友圈一段各拆为两段 → 原因：长段拆短，雷击“咔”与扫码“嘀”各占一拍，路口渣土车辙单独成段，为第27章事故留下更醒目的伏笔。
- “下午他又睡了一觉，这在以前想都不敢想，以前别说午觉，夜里都睡不着。” → “下午又睡了一觉。搁以前，别说午觉，夜里都合不上眼。” → 原因：去重复“以前”，句子更利落。

## 对话
- “‘我娘腌的。’他说，‘她让我……’” → “‘我娘腌的。’孟实把罐子往前推了推，‘她让我……’” → 原因：去“说”字标签，用动作带出孟实的拘谨嘴笨。
- “‘咸了点。’他说，‘好吃。’” → “‘咸了点。’他咽下去，‘好吃。’” → 原因：台词不动，标签换成吃的动作，两句之间多了一拍，更像老耿。
- “‘耿师傅，我站了一个多月了。’他说” → “……他搓了搓发麻的手指” → 原因：用站桩后的身体细节代替标签，带出孟实问出口的不安。
- “阿杰说得很快，像怕被打断” → “阿杰一口气往下说，生怕被打断”；“‘你这阵子，睡得着吗？’他问。” → 删“他问” → 原因：减少“像”和对话标签，阿杰的急和孟实的实诚靠台词本身立住。

## 文笔
- “纸箱泡软了，一提就塌，里面的东西撒一地” → “纸箱泡软了，一提就塌底。洗发水、数据线、小孩的塑料凉鞋撒一地” → 原因：补具体物件，复核台的雨季更可感。
- “女主播的声音被打饭的吵嚷盖了一半” → “不锈钢餐盘磕得叮当响，女主播的声音被盖了一半” → 原因：用声音细节代替概括。
- “雷声滚过河面，在桥洞里嗡嗡地回响。” → “……在桥洞的拱顶底下来回撞。”；前文车过桥“嗡嗡地响”→“轰隆隆地响” → 原因：同一场景两处“嗡嗡”去重。
- “‘开了口子了。’老耿说。” → 删“老耿说” → 原因：上一段已写老耿的脸，台词单独落地，更有分量。

## 爽点
- 本章为蓄水章，无释放。三条压力线全部保留：余额比三月初少十一块（经济）、阿杰借钱沉默三分钟（人情）、赵小满约在槐荫路口靠路边那张桌（伏笔），渣土车辙与站台漏雨的路口描写保持完整。
