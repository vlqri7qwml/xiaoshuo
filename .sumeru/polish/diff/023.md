## 节奏
- “拿笤帚把墙角的蜘蛛网够下来，把化肥袋子挪到外头棚子里，把那台坏缝纫机擦干净……地上洒了水，又扫了一遍。” → “墙角的蜘蛛网够下来，化肥袋子挪到外头棚子里，坏缝纫机擦干净……洒了水，又扫一遍。” → 去掉一串“把”，干活的节奏短促利落。
- “孟实接过清单。一列一列的药名，后面跟着数字。账户余额那一栏，剩一百零几块。” → “孟实接过清单。账户余额那一栏，剩一百零几块。” → 直奔数字，省下篇幅给楼梯间的撕裂。
- “五楼的走廊灯全亮着。十六床围着帘子，里头有人说话，脚步杂乱。” → “十六床围着帘子，里头脚步杂乱。” → 病重夜压缩场景交代，把镜头直接推到监护仪数字上。
- “上面印着父亲的名字，诊断，一行一行的字。孟实一个字一个字地看，每个字都认识，连在一起，脑子里就是一片空白。” → “上面印着父亲的名字和诊断。孟实从头看到尾，看完一行，忘一行。” → 去套话，短句写出脑子发木。

## 对话
- “孟实问她，血氧多少算好。她说九十往上。” → “孟实问她血氧多少算好，她脚都没停：‘九十往上。’” → 用动作带出“说话像赶路”。
- 孟实：“不是舍不得——” 母亲：“那是啥？！” → “我没舍不得——”“那你图啥？！” → 去“不是A”句式；“图啥”是村里人的质问口气，更扎。
- “她笑了一声，比哭还难听。” → “她笑了一声，短短的，干的。” → 去套话，克制地写出母亲的绝望。
- 老耿“别碰，别烧，别骂，也别求”“钱，花在医院”“站你的”“我不是医生”“长途，贵。挂了。”，母亲“孟实，我这辈子不原谅你”，二叔“信邪，不信祖宗”，邹婶“好心当成驴肝肺！”原样保留，仅去掉部分“说”字标签。

## 文笔
- “孟实看着手机屏幕暗下去，忽然想笑。这年头哪还有什么长途。可他笑不出来，鼻子更酸了。” → “这年头哪还有什么长途。孟实想笑，没笑出来，鼻子更酸了。” → 精简，苦笑一笔带过。
- “靠着条案的那半边身子，总是绷着。” → “挨着条案的那半边身子，一直绷着。” → 用词更准，只写紧张不写感应。
- “电动车的灯昏黄昏黄的，只照得见前头几米。乡道两边的麦地黑压压的，风从耳边刮过去。” → 合为一句，保留“慢得他想下来推着跑” → 急切靠动作，不靠环境堆叠。

## 爽点（加压章：钱、孝、信三股劲撕开写透）
- 楼梯间独处段新增“钱”：“这个月请了一周事假，工资本来就要少一截，十五号发下来，还得先扣借支的七百多。八千块要凑，只剩一条路：手机上那个借钱的入口……阿杰那十四万，就是这么一下一下点出来的。” → 把凑八千的唯一出路摆到眼前，并和阿杰的债勾连。
- 新增“孝”：“账算得清，孝算不清。在孟家洼，孝就一个字：顺……借了是孝，不借就是不孝，跟钱花在哪儿没关系。” → 写出乡土伦理里“孝=顺”的硬逻辑，孟实想辩又不能辩。
- 新增“信”：“他要是借了这八千，就得认明白人那个理……他要是不借，就得认老耿那一句……可老耿凭什么？……爹的命，拿什么去试？” → 两头都要“信”，两头都没底，孟实对老耿的信也只建立在自己身上。
- 新增落点：“反过来呢？借了八千，做了法事，爹还是没扛过去，也没人会怪他……原来那八千块，买的是这个。买的是往后谁也说不了他一句。” → 三股劲拧到一处：八千块买的是儿子的“免责”，不是父亲的命。领悟落在具体的钱上，不说教。
- 收尾“再熬熬”“像看一个仇人”原样保留，压力压到最低点，交给第24章释放。
