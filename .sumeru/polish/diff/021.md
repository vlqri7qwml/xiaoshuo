## 节奏
- 阿杰“刚入会那会儿……再后来，是心跳。”一整段 → 拆为两段，中间插“阿杰弹了弹烟灰。” → 醉话一顿一顿往外倒，节奏更像真人说话。
- “中午主桌上那张红光满面的脸，像是拿什么东西硬撑起来的，到了夜里，撑不住了。” → 删“像是拿什么东西硬撑起来的” → 去冗余比喻，也避免暗示“有东西”，守红线。
- “他想了很久，才开口。说得很慢，每个字都掂量过。” → “他想了很久，才开口。” → 去重复交代，让后面结巴的话自己体现“掂量”。

## 对话
- 孟实劝阿杰：“先停一停吧。……这不是小事。” → “杰子，我……说句话”“先停停吧……上个大医院，挂心内科……这不是闹着玩的。”并补“他嘴笨，翻来覆去就这几句。” → 孟实嘴笨实诚，说不出漂亮话，只有最土的那几句。
- 阿杰“你就是嫉妒！”“你自己没福报，见不得别人好！”“我不能停。停了，前头的全白了。”一字未动；老耿那句“借来的，早晚要还。还的时候，不是钱。”原样保留。
- “‘人家那是高兴，’另一个婶子说” → “另一个婶子把一根烂菜叶子扔进簸箕” → 去标签，用择菜动作带出乡下门口闲话的场面。
- 母亲听见“气色好多了”：原只“嘴角往上弯了弯” → 补一句“白班，能按点吃饭。” → 回扣第19章孟实原话，母亲不炫耀，只把儿子的话原样递出去，是她的体面。

- “现在不一样了，它自己来。” → “现在它自己来。” → 删去冗余，感应仍只做客观描写。

## 爽点（倾泻章：压抑→蓄力→释放→余波）
- 压抑：阿杰骂“一辈子在仓库扛箱子的命”保留，叠在第20章满桌哄笑之上。
- 蓄力：路过村小学想起鞋垫、想起“他的事就是我的事”保留 → 释放之前先把情分摆出来。
- 释放（重写）：原“他心里没有一点痛快。” → 改为先回放中午的笑声（“这叫挺好？”“福报浅”“闷屁”），再“憋了一天的那口气，在胸口松开了。／就松了那么一下。”，随即“想起石碾子上那只抖个不停的手……那只鞋垫。／松开的地方又堵上了，堵得比中午还实。／他宁可中午那些人笑得再响一点，也不想知道今晚这些话。” → 暗爽是真的，心疼也是真的，两股劲同时落在一个人身上，不让孟实高调，也不假装他毫无波澜。
- 余波（新增）：婶子们夸阿杰“有出息的人，应酬多”时，加“孟实手里的凳子腿硌着掌心。／他只要张一张嘴，这门口的话头就全翻过去了。／他没张嘴。昨晚答应过的。” → 真相握在手里却不用，爽点落在克制和信义上，同时回扣“谁都别说”。
