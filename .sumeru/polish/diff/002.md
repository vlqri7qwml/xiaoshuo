# 第2章 修鞋的老头 润色修改说明（中度）

润色前 3384 字 → 润色后 3379 字。开头“孟实没接话，转身就走。”与结尾“反正不要钱。/还能更坏吗？”原样保留；老耿台词（“后生，坐。”“鞋底开了，是走的路不对。”“五块。”“没码。现钱。”“不要钱。”“你要信，明儿傍晚来帮我收摊。五点。”“不拜。”“不买。”）一字未动。

## 节奏
- “槐荫里的巷子窄得两个人错身都得侧着走，头顶上的电线乱得像一团没理开的毛线。” → “槐荫里的巷子窄，两个人错身都得侧着走。头顶的电线缠成一团……” → 原因：长句拆短，删多余比喻。
- “他拖着那只鞋，一步一步踢踏着往回走。” → “他拖着那只鞋，踢踏着往回走。” → 原因：去掉重复修饰。
- “穿着补好的鞋走在槐荫里的巷子里” → “穿着补好的鞋走在巷子里” → 原因：去“里……里”重复，转场更利落。

## 对话
- “孟实在摊子前站住，把塑料袋往前一递，硬邦邦地说：‘补鞋。’” → “……往前一递：‘补鞋。’/硬邦邦两个字。” → 原因：去掉“地说”，把语气单独成段，孟实的戒备更显。
- “‘……鞋便宜。’他说” → “他憋出一句”；“‘没码。’老头说” → “老头头也没抬” → 原因：用动作代替“说”，孟实嘴笨、老耿不搭理，都靠动作带出来。
- “这一套我见多了” → “这一套我……我见多了”；“他越说越快。” → “他越说越快，舌头跟不上，话都撞在一块儿。” → 原因：孟实嘴笨，这段爆发是憋出来的，加一处磕巴，避免他突然变得能说会道。
- 赵小满“赵小满说，声音却是虚的” → “赵小满嘴上不饶人，声音却是虚的” → 原因：点出他嘴碎心善的反差。

## 文笔
- “不是灯灭了。灯还亮着，可他什么也看不见了” → “灯明明亮着，可他什么也看不见了” → 原因：清理“不是A，是B”句式。
- “脑袋像灌了铅” → “脑袋又沉又胀”；“像一张咧开的嘴” → “咧着一张嘴”；“匀匀的，密密的，像机器轧出来的” → “匀匀的，密密的” → 原因：本章“像”字比喻从 9 处压到 2 处，只留“放凉了的白开水”这一个写老耿的关键意象。
- “孟实站在那儿，像一拳打在了棉花上。” → “孟实站在那儿，一拳打在了棉花上。” → 原因：去比喻词，口语更直。
- 补感官：“拧开一个铁皮罐子，一股胶水味冲出来，辣眼睛”；“纸箱棱子勒进指头，箱子里的猫砂沙沙地往一头坠” → 原因：补嗅觉、触觉，让补鞋和搬货两场戏更实。

## 爽点
- 本章为加压章：房东“一身晦气”、鞋底整块开胶、眼前发黑三重压抑原样保留；“不要钱才最吓人”推演未删（第 4 章同类推演由该章压缩），结尾“反正不要钱，还能更坏吗？”的反弹落点不动。
