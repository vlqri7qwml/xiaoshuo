# 第24章 黑水 · 润色修改说明（中度）

润色前 3154 字 → 润色后 3316 字

## 节奏
- “‘这是澜城第一医院下来对口帮扶的，’主任说，‘在咱们科轮转半年，今天头一天。’” → “主任抬手一指：‘这是澜城第一医院下来对口帮扶的，在咱们科轮转半年，今天头一天。’” → 一句话说完，查房节奏不被标签打断。
- “‘记得挺细。’他说，‘往后接着记。’” → “‘记得挺细。往后接着记。’” → 前文已交代是年轻医生，标签多余。
- 二叔“说：‘大哥，你这是命大。’” → “站在床边看了父亲半天：‘大哥，你这是命大。’” → 去标签，“看了半天”带出二叔的心虚与服气。

## 对话
- “‘医生说了，不让吃咸的。’母亲说着，嘴角往上翘了一下。” → “母亲嘴角往上翘了一下。” → 去“说着”，笑意直接落在动作上。
- “她忽然小声说：” → “她忽然开口，声音很小：” → 减少“说”字，母亲的和解话更像从嗓子里挤出来。
- “‘这家运气好，’一个护士说” → “一个护士笑” → 护士闲聊的轻松，与孟实心里的分量对照。
- 母亲“你去眯一会儿”“不那么阴了”“我晚上进去都不怕了”“替我谢谢那个补鞋的师傅”原样保留。

## 文笔（黑水之梦：加画面、加分量，两种前世都不点破）
- “深到光照下去，连一点回响都没有。” → “看不见岸，或者岸就在他脚下，他也说不准……连个影子都映不出来。” → 去掉视觉、听觉错搭的比喻，改为“无岸、无倒影”两处可见的画面，黑水的“沉”更具体。
- 新增“有一回，一点亮落得近，就落在他跟前。他想伸手去接，才想起自己没有手。” → 用一个动作写出“没有形体、守了太久”的孤独，不交代他是什么。
- “可那是什么，为什么要守，他从来没问过” → 补“是谁让他守的，他也想不起来。也许有人交代过他，也许他生来就在这儿。” → 并列两种来历：受命而守（仙人线），生来在此（穴场/妖魔线），两条都成立，不偏向任何一边。
- “那声音不是从哪个方向来的。不远，也不近；不像是命令，倒像是有人开了一扇门” → “听不出从哪边来，也听不出远近。语气平平的，没有催他的意思，像有人在他身后推开了一扇门” → 清理“不是/不像是A，倒像是B”句式；“去吧”保留原样，说话者身份不点破。
- 新增“身后那片黑水还在……水底那个很沉的东西还压在那儿。他走了，谁守着它？” → 给“想进又怕”加一层分量：向往人间与放不下职守同时拉扯；水底之物仍只写“很大，很沉”，不写形状、不写惊悚。

## 爽点（倾泻章：压抑→蓄力→释放→余波）
- 压抑：开头病重夜、母亲整夜不说话保留，承接第23章“像看一个仇人”。
- 蓄力：年轻医生看孟实手机备忘录、“记得挺细。往后接着记。”保留 → 孟实“钱花在医院”的笨办法第一次被专业的人认下。
- 释放（补强）：退烧后新增“走廊尽头的窗外，天刚放亮。他隔着裤子摸了摸兜里那张收据。四千六，薄薄一张，还在。” → 回扣第23章“唯一能抓住的东西”，释放落在一张收据上，不让孟实说一句硬话；紧接母亲“你去眯一会儿”、二叔“法事的事，一个字没提”。
- 余波：护士“运气好”、母亲托谢补鞋师傅、“车开了，往南，往澜城。”原样保留，接第25章。
