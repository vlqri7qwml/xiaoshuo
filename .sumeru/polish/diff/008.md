## 节奏
- “他穿这身来，是没办法。体验课两点到六点，下了课得直接去东郊上夜班，回槐荫里换衣服就赶不上了。” → “体验课两点到六点，下了课得直接去东郊上夜班，来不及回槐荫里换衣服。” → 压缩交代。
- 删去“他停了停。”（贺明远提问前）、“说难也难，说简单也简单” → 贺的讲话更顺，把篇幅留给哄笑段。
- “阿杰说。/门合上了。” → “阿杰伸手挡了一下门：‘名额我先给你留着。’/手一松，门合上了。” → 关门动作连贯，电梯镜子段落接得更紧。

## 对话
- “‘我不送件。’他说，‘我上28楼，找人。’” → “‘我不送件。我……上28楼，找人。’” → 去标签，一个停顿带出孟实被当成送件工的窘迫与嘴笨。
- “‘大家不要笑。’他说，‘谁不是从这一步走过来的？’” → “‘大家不要笑。谁不是从这一步走过来的？’” → 贺明远的话本身足够体面，不需要标签。
- “‘我……’孟实说，‘我再想想。’” → “‘我……’孟实嗓子发干，‘我再想想。’” → 用生理反应替代“说”。
- “频率低了，高维的东西什么都往你身上凑” → “频率低了，乱七八糟的东西都往你身上凑” → 原句语义拧巴，改后符合贺明远“会说话”的人设，也避免暗示妖物。

## 文笔

- “笑声像水一样漫开，一浪推着一浪” → “笑声从前排漫到后排，一浪推着一浪” → 去比喻，改成空间方位，更写实。
- “他想说点什么，喉咙里像塞了一团棉花。” → “他张了张嘴，一个字也没出来。” → 去套话式比喻，用动作写哑口。
- “这不是明摆着吗？” → “这还用说吗？” → 去“不是”句式，语气更像自问自答的认命。
