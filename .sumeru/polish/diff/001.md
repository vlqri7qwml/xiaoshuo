# 第1章 夜班 润色修改说明（中度）

润色前 3508 字 → 润色后 3481 字。开头“嘀。”与结尾“像什么话也没说过。”原样保留；老耿台词“后生。”“你背上驮的东西不轻啊。”未动。

## 节奏
- “这是他连着第四天睡不着觉。” → “这是他连着第四天没睡着觉。”；第 2–3 段改为“孟实手腕一翻……下一件已经顺着皮带拱到了他手背上。/凌晨三点，通衢物流园分拣中心，三号线。” → 原因：全书开篇，前三段用动作和触感直接把读者放到流水线上，“三号线”提前点出，地点、时间、身体状态三句交代完毕。
- “早上八点下班……接着上夜班。”一整段 → 拆成“眼睛闭着，脑子醒着。”与“楼下的电动车喇叭……”两段 → 原因：长段拆短，便于手机阅读，失眠的循环更有节拍感。
- “开往城里的公交八点十分到站，车门一开，人往里涌，挤得跟沙丁鱼罐头似的。” → “进城的公交八点十分到站，车门一开，人往里涌。” → 原因：删套话比喻，转场压缩。
- 改命经历中“灵修营”“坠子”两段各拆成两段 → 原因：信息密集的回忆段落拆短，节奏更匀。

## 对话
- “还不快去！等装上车拉走……”保留；新增马红霞一句“还低头看鞋？鞋能替你分件？回线上去！” → 原因：前面替孟实求情是“豆腐心”，这一句补上“刀子嘴”，也替原来生硬的“他回到三号线”接了个转场。
- “孟实张了张嘴，说：‘对不住。’” → “孟实张了张嘴：‘对不住。’” → 原因：去掉对话标签，动作带出说话人。
- “‘巧克力，吃了。’赵小满说，‘你这脸色……’” → 合并为一整句台词；“‘谢啥，过期的。’赵小满说” → “赵小满手上没停” → 原因：减少“说”字标签，用动作提示他一边干活一边嘴碎。
- “马红霞在边上动了动嘴”“周广发打断她”去掉冗余部分 → 原因：插话本身就是打断，不必再标。

## 文笔
- “‘嘀、嘀、嘀’，像一屋子停不下来的闹钟。” → “一屋子停不下来的闹钟。” → 原因：本章“像”字比喻 12 处，压到 6 处，保留最有力的几个（湿被子、两拳、老树根）。
- “眼眶里像揉进了一把沙子。” → “眼皮底下干得发涩，一眨就疼。” → 原因：换成身体直接感受，去掉常见比喻。
- “腿是软的，不全是吓的，这几天他走两步就发飘。” → “腿是软的，一半是吓的，一半是这几天熬的，走两步就发飘。” → 原因：清理“不是A”式否定句，改成并列，更口语。
- “看得孟实脚底下像钉住了。” → “看得孟实挪不动脚。”；“后脊梁一凉，像有人往他领口里塞了一把雪。” → “孟实后脊梁一凉。” → 原因：结尾前收紧，减少修辞，让“那一句话，三千六”落得更干脆。
- 包子铺补一笔“带着面肥的酸香” → 原因：补嗅觉，增强城中村早市的烟火气。
