## 节奏
- “他想起上午在群里看那篇文章的时候，心里有那么一个小角落……” / “他又想起刚才那句……” → “上午在群里看那篇文章的时候，他心里有那么一个小角落……” / “还有刚才那句……” → 去掉两个连用的“他想起”，两层反省直接并排放，读起来更利落。
- “孟实打开纸盒看了一眼，里头是六瓶水” → “孟实打开纸盒，里头是六瓶水” → 删掉冗余动作。
- “最上头是一篇转过来的文章，来自明心灵修会的公众号” → “……明心灵修会的公众号” → 去掉书面腔的“来自”。

- “‘去会里调理。’”（说话人不清） → “‘去会里调理。’男的抢着答。” → 补出说话人，“抢着”带出会里的人急着把人接走。
- “‘家属自己负责。’男的说。” → “‘家属自己负责。’” → 上一句已交代是男的在答，删掉标签。
- “‘婶，医药费的事咱先不说。’他说，‘阿杰中午吃饭了没？’” → 去掉“他说”，两句连成一段 → 孟实嘴笨，话不绕弯，连着说更像他。

- 老耿那句“他自己要回头，才有路……”原样保留。
