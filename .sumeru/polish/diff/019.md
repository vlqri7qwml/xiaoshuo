# 第19章 衣锦还乡 · 润色修改说明（中度）

润色前 3324 字 → 润色后 3339 字

## 节奏
- 开头布包一段（药、红包、四百块信封挤在一段） → 拆成“孟实靠着车窗……搂了搂。”和物件清单两段 → 一段只做一件事，适合手机阅读。
- “那句话他在床上翻来覆去想到半夜，以为今天准得熬得眼睛发涩，结果没有。”与站桩同段 → 单独成段，并改为“本以为……结果没有” → 把“车上睡着”这个变化落在独立段落里，蓄水章的身体变化更醒目。
- “然后就没有然后了。” → “话就到这儿了。” → 去网络腔，乡亲寒暄戛然而止的冷淡用平实口吻写。
- “在县客运站转了去镇上的中巴，又在镇口搭了一段顺路的三轮，到孟家洼村口的时候，已经过了晌午。” → “县客运站转中巴到镇上，镇口再搭一段顺路的三轮，到孟家洼村口，已经过了晌午。” → 转场压缩，路线事实不变。

## 对话
- 赵小满“别拿超市买的糊弄我！” → 补“我尝得出来！”并追加一条“多带点，我拿它下泡面。” → 嘴碎、馋，又透着打工人的穷日子。
- 邹婶只有炫耀 → 补“就是瘦了。在外头，吃不上一顿正经饭。”／“没人接这句。大伙儿又去看车了。” → 邹婶不脸谱化：嘴上显摆，心里还是当妈的；同时给阿杰透支埋一笔，全村只看车不看人。
- “不是科技，是频率。” → “啥高科技，那都是低维的。人身上有频率……” → 去“不是A，是B”，换成阿杰会里学来的话术口吻。
- “‘看看看，’有人说，‘人家这是高科技。’”／“阿杰说”“她说”“母亲说” → “后头有人接茬”“阿杰拍拍胸口”“母亲的筷子在碗沿上停了停”等 → 少用对话标签，用动作带出说话人。

## 文笔
- “像开着分拣线” → “跟分拣线没停一样” → 比喻落到孟实熟悉的噪声上，口语化。
- “比村里任何一辆三轮车、任何一辆摩托都显得金贵” → “旁边的三轮和摩托都矮了半截” → 用画面代替判断，和后文“三间房矮了一截”呼应。
- 父亲出场“咳得很闷……硬拽出来的。” → 补“比过年那会儿重。” → 落实细纲伏笔“父亲咳得比过年重”。
- “也是这么跟人说的”原为“在那家灵修营的头一个礼拜” → “从那家灵修营回来的头一个礼拜” → 与第18章“回来那一个礼拜，一天睡三四个钟头都不困”对齐，七天营本身不足一礼拜。
- 删“心疼得直咂嘴”的“心疼得”、“精神头足得很”的“很”、“搂得很紧”改“搂得死紧” → 去空洞程度词。

## 爽点（蓄水章：只蓄不放）
- 母亲“你……胖了点？”、父亲“嘴角往上牵了一下，又压了下去”原样保留 → 孟实的变化只从亲人眼里看出来，克制。
- 阿杰“一天睡四个钟头，一点不累”与孟实“车上睡着、嘴角挂口水”同章对照，不加评论 → 为第21章倾泻埋对比。
- 结尾“坐哪儿都一样吃。”及灶膛“啪”一声原样保留 → 压抑收在平静里，接第20章。
